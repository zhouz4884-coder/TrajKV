# 新主线目标：一比特失效的可修复结构

依据用户最新指示，主线从固定K2/V1配比，转为检验编码电平、视觉尺度和token幅度能修复多少一比特失效。原1.8-bit存储/读取研究作为已完成开发对照保留，新64确认尚未启动。

## 目标

在相同骨干、图像处理、分组和问答协议下，争取以约1.25–1.35实际bit/KV scalar保持接近2-bit的任务质量。先比较同工作点K2/V2 minmax，再挑战与预先冻结的强质量参考差距≤0.5pp。账本含量化参数、token增益、位置/索引及辅助存储；编码成本、缓存读取与时延分列。

## 三项主实验

1. **A，编码电平**：同轴同g128同格式，比较minmax、零中心sign/mean-abs、均值中心MAD、Lloyd双质心。单侧FP16对照先分解K/V，再测联合1-bit。V采用token/channel×编码方式的正交对照，不把轴变化当作中心收益。
2. **B，token幅度**：在相同符号表示上添加每token/KV-head一个FP16增益，约增加0.125 bit/K scalar、0.0625 bit/KV scalar。比较最小二乘与中心化范数匹配；有中心时重构为 `center + gain * (base-center)`。不预设它精确恢复原norm或排序。
3. **C，分段温度与机制**：视觉attention logits乘数覆盖0.15–0.5，文本段保持不变；用全局缩放控制区分模态尺度失衡与一般温度效果。输出词表正温度不改变greedy argmax，不能拿来诊断。

## 理论要求

可证明的基础是固定中心下对称两电平的mean-absolute最优性、固定符号模板下的最小二乘增益。高斯14.3倍只是特定范围的例子，真实KV按组测量。

SNR=1不是普适的attention排序门槛：整体正比例放大可有很大误差但完全保序，极小top1间隔也可在高SNR下翻转。SNR作为待验证代理，同时测query条件协方差、score偏置/尺度、排序、attention分布和投影输出误差。

V量化包含非线性sign，不能整体视为可吸收的线性重参数化；均方误差平均化需要误差相关性条件。ANLS中多字符数字串错一字不一定归零。

## 证据和确认

质量同时报告ANLS、exact、固定文本下的FP16-logit KL和参考答案平均token log-prob；按原始图像聚类统计。编码/增益的效果和交互项分别报告，不预写60%/40%归因。

旧dev8和20读数题用于机制与参数选择；候选冻结后才运行新64。若MAD或增益未达预期，修改该假设的解释，保留已测1.8-bit方法作资源对照，不因单个数值门提前停止研究。

读取支线在固定实际存储下比较不精化、全精化、Periodic、Random、Mass、Impact；逻辑读取与实测时延分别报告。共享coverage/码字需真实实现和计费后再纳入主张。
