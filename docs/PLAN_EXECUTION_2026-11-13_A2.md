## 研究问题与可证伪预测

A2 保留所有视觉 base KV，仅对当前读取事件选定的页补 K-r2/V-sign 残差。预测：在相同存储与包含选择开销的读取额度下，query 与误差元数据的组合可能比随机、均匀、mass-only 选页更有效。排序稳定不等于输出稳定；raw MSE 集中或 CS 证书通过率都只是描述量，不作前置否决。

C 在相同视觉表示下驱逐部分文本历史并真实释放其 KV 所有权，保留原始位置。区分部署式删除与干净重编码；测试视觉可再得事实和对话独有约束的条件价值，比较同 role/recency 规则，不将边际损失解释为可加的信息量。

## 资源与比较口径

存储计 packed base、残差、标量/向量元数据、位置和实际拥有的文本 capacity；另列模型权重与 allocator peak。读账是显式 tensor payload 的逻辑字节，不称实测 DRAM。额外 qK_base 选择扫描、元数据读取、残差、scratch 和重算分列。预算按前缀大小/读取次数缩放，旧 16 MiB 另列。没有能用的 HBM profiler 时只报告逻辑账及同步实际耗时。

先实现可复核的 qK_base 数值参考，再测 metadata-only 候选；参考分支和未来答案不得作为部署特征。所有样本和失败保留。有限动作库的事后最优仅为 oracle 参照，不能逐题从不同自由生成轨迹拼成可部署方法。

K-only/V-only 与 CalibQuant 按实际码率比较；不把有 2-bit K 残差的 Base1 称作相同 1-bit。KVarN/Calib 的 materialized 数值移植只作质量参考，速度不能冒充 packed serving 性能。
