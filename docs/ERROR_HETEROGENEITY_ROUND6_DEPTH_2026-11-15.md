# Round6 深度配置：开发与新源确认的逐题错误和异质性

日期：2026-11-15。本文只读已完成的 dev64 与新源 Doc54 评分及深度诊断；不改冻结方法，不使用新源结果调参，不新增 GPU 实验。原冻结候选仍是 `r6_depth_v_pair`，新源上分数最高的 RD 不替代原候选。

**当前固定 Pair 配置的开发收益没有在新源复现。** 相对同格式、同完整字节的 incumbent，dev64 为 +1.3123 pp，新源 Doc54 为 −1.3278 pp；两组都只有 10 个题目的 ANLS 发生改变，但改善/伤害及幅度不同。Pair 第二级 V 的真实源失真比例几乎保持：dev `D2/D1=0.404223`，新源 `0.403542`。编码器仍能压低剩余源误差，静态集中精度的任务收益却没有随之稳定迁移。

## 1. 配对方法与统计边界

使用 `scores.csv` 中 `(session_id,turn)` 一一匹配 Pair 与 incumbent，独立核对参考答案、源文档、图像、视觉 N 与冻结 numeric 字段相同。改善/伤害按 ANLS 差值正负定义；绝对差值 ≤1e-12 为同分。同分可以包含不同预测字符串，不等于 token 序列相同。

总体仍按原评分的题目权重汇总；源文档表保留每源内均值以及该源对全部题目 score 总差的精确贡献。这里的 visual-N 与答案类型分层是**事后描述**，不新增分层显著性检验，不用这些分层重选候选或宣称机制。

开发主比较 bootstrap 区间为 [+0.1577,+2.7935] pp，但文档配对双侧 `p=0.063809`、探索比较族 Holm=0.433156；原开发结果本来就不是确认。新源 Pair−incumbent 为 −1.3278 pp，区间 **[−3.9189,+0.8342] pp**，`p=0.375936`、Holm=1。新源点估计反向，且没有确认正收益；这不等于统计证明所有深度配置都更差。

最主要的 N=1792 层内部也从开发正向变成新源负向，因此反转不能只用两组 N 构成不同来解释。N=1280 新源损失更大，但仅来自 3 个源文档、9 题；N=1024 只有 1 源、4 题。不能据此制定“N 较小就不要两级”的部署规则。

实际整数预算同时变化：新源 N=1024 使用 41 个总 stage（24K +17V，Pair 为 8 个两级 V 加 1 个一级 V）；N=1280 为 42 个 stage，N=1792/2304 为 44。这些变化都由完整字节计算产生，不能将所有新源图像描述成固定 10V×2，也不能把 N 与内容、覆盖数的共同变化当作已分离的因果作用。

## 4. 数字参考与其他参考

沿用冻结 scorer 的 `numeric`：**任一参考答案字符串包含任一数字字符**。这包括日期、电话和字母数字混合答案，不是纯算术题或纯数字答案分类。分层使用参考答案，属于评测后的解释信息，不可当作部署时已知特征。

| 样本 | 参考类型 | 题数 | 改善/伤害/同分 | Pair−incumbent |
|---|---|---:|---|---:|
| dev64 | 含数字字符 | 118 | 4 / 0 / 114 | +1.3983 pp |
| dev64 | 其他 | 137 | 3 / 3 / 131 | +1.2382 pp |
| 新源 Doc54 | 含数字字符 | 87 | 0 / 3 / 84 | −2.6273 pp |
| 新源 Doc54 | 其他 | 118 | 4 / 3 / 111 | −0.3697 pp |

开发数字参考的 4 次改善包括日期、金额等不同文本；新源的 3 次数字参考伤害中，2 次是同一 snkw0227 文档的重复年份错误，另一次是 nxnw0228 的金额。它们是按源聚集的少量事件，不是 3 个独立来源对“数字更难”的证实。非数字参考也有 −1 的语义选择或输出扩展损失。

这里可以提出“覆盖减少可能影响某些证据定位或输出选择”的假设，不能得出“第二级损坏数字”或“二级对 OCR 无效”的机制结论。沿用原 source-document 聚类统计，正是为了避免把同一图像的多问错误当作独立重复证据。

## 5. 机械失真能力保持，任务排序反转

| Pair 实际存储单元诊断 | dev64 | 新源 Doc54 |
|---|---:|---:|
| K 一级 D1/D0 | 0.351266 | 0.351320 |
| V 一级 D1/D0 | 0.336586 | 0.336533 |
| V 二级 D2/D1 | 0.404223 | 0.403542 |
| 二级 V 图像×单元观测数 | 637 | 535 |
| 单观测二级比例范围 | 0.381698–0.474863 | 0.381090–0.478110 |
| 二级比例中位数 | 0.410082 | 0.409647 |

这些数据来自真实逐级 FP16 重构；K 在中心化 FWHT 域、V 在原坐标。比例用各自实际二级单元的 MSE 总和相除。新源还有一个只存第一级的 V 图像×单元观测，不进入 D2/D1 分母。两组各自的图像与单元预算分布不同，因此数值接近是描述性观察，不是形式等价检验。

第二级在两组中都降低约 60% 的已有 V 源误差，没有出现明显的源失真衰减崩溃；但 Pair 对 incumbent 的答案分数差反向。由此能排除“只有开发数据才看得到二级码的源误差下降”这一说法，不能证明到底是覆盖、状态漂移、局部误差方向还是生成变化造成任务反转。

要比较任务效用，交换包含两部分：一边在较早 V 候选上增加第二级，另一边撤去后续候选的第一级覆盖。D2/D1 只测前一边相对其自身 D1 的改善，未测后一边在完整模型中的机会成本；K/V 源误差还要经过完整 softmax、文本 mass、W_O、后续层和自由生成。机械失真比例接近，从来不保证这些因素相同。

开发集为 Pair > incumbent > RD；新源描述性排序为 RD 89.9462、Pure-V 89.6058、incumbent 89.4294、Pair 88.1016。新源 Native4 为 86.9822、Full 为 88.0459。Full 作为参考的点估计较低不自动说明低比特有普遍正则化收益；RD 在这些冻结候选中最高，也不把它追认为原 primary，或据此重新使用新源调参。冻结 Pair 的开发主张没有获得预期确认，这一结果应原样报告。

## 6. 研究判断：先保覆盖，有限 stage 价格用于选择性交换

**当前证据不支持静态一律集中精度。** 这句话针对当前固定 Pair 比例在所有图像上的应用，不是宣称任何静态深度规则都不可能成立。实际两级 codec 是有效编码能力；统一牺牲覆盖来使用它，尚未得到可迁移的任务收益证据。

下一步在“覆盖约束”与“stage 有限价格”之间，应把**保留覆盖作为更直接的工程约束**。它直接限制这次操作中被牺牲的自由度，并保留已在新源较稳的宽覆盖控制作为默认起点。它的合理性来自风险约束和当前两组结果，并不是本分析已经证明“损失就是覆盖不足所致”。固定更多覆盖是否真能改善，仍需在另一个授权的校准/开发阶段接受实际对照，不能回到当前新源调比例。

**stage 有限价格是检验和改进选择的工具，尚不是已经验证成功的分配规则。** 更有信息的对象应是实际同预算交换：

`G(u←v;S)=ℓ(S)−ℓ(S−v+u)`，

其中 u 是合法新增一级/二级 stage，v 是撤去的 stage，并在新鲜缓存、相同学生前缀下评估。只测新增二级的 `D1−D2` 或独立梯度内积，会漏掉撤去覆盖的机会成本以及交换后的状态变化。可以用 Student 梯度筛少量候选，但应以有限交换的真实损失和跨问题稳定性决定是否偏离覆盖下限。

现有局部 4 动作×16 case 的良好 Student CE R² 支持继续把梯度用于这种小范围筛选；先前全局方向性排序和 RD 的开发表现则提醒，不能把它直接升级为全图、全阶段任务价格定律。较有根据的顺序是“默认保覆盖、少量有限交换证明集中值得后再集中”；而不是在当前确认集上重新选一个更好看的静态比例。
