# TrajKV第五轮研究进展：表示确定以后，精度该补在哪里

本轮最有价值的结果，是把约1.58bit的视觉缓存推进到一个有实际质量收益的≤1.8bit表示：保留便宜的K方向PQ，将余量用于少数单元的紧凑符号残差。独立新Doc64图/256问上，冻结主候选Mixed-grad达到91.445 ANLS，完整成本1.79942bit；相对Base2改善3.627pp，预定主比较族的Holm p=0.02436。但距离Native4仍差2.050pp，0.5pp目标未达，当前也不能将新估计器或统一最优分配写成已成立的贡献。研究主线应围绕**依赖当前表示的边际精度价值**及真实编码组合收紧。[新Doc确认结果](../results/round5_v1/doc_confirmation_summary/summary.json)

## 数据与证据范围

cal16仅用于统计、校准及冻结排序；首16图/62问是开发64图/255问的子集，不能当两次独立验证。前四节保留开发与机制证据；第五、六节另报方法冻结后完成的全新Doc64图/256问与新鲜Text64图/64问，不混合计算。Text使用官方VQA软准确率，不能与Doc的ANLS直接比较。[开发样本口径](../results/round5_v1/development64_analysis/summary.json)

质量评测使用两张3090上的完整模型自由生成，实际packed reader保留全部视觉token，文本KV为FP16；新增数据、结果与编译缓存均放数据盘。谱投影另作为材料化机制原型报告，不混入低比特部署前沿。

## 一、预算补V产生了可复核的质量空间

当前底座的K是256码字、4维product code，即2bit/K元素，另有每token增益与均值；V为1bit整图通道量化。方法离线在layer×KV-head单元上作有限干预，按同q、同文本状态下经W_O汇合后的输出收益冻结排序。部署只保存预算允许的残差前缀，读取时融合解码；未选单元保留base，原始视觉FP16不常驻。

| 开发64图/255问 | ANLS（%） | 完整bit/KV scalar |
|---|---:|---:|
| Full | 92.004 | 16.0022 |
| Native4 | 92.079 | 4.2522 |
| Base2 | 88.966 | 2.2522 |
| 原整图底座 | 87.230 | 1.5786 |
| V残差，有限输出收益排序 | **90.771** | **1.7993** |
| V残差，随机分配 | 88.212 | 1.7993 |
| V残差，分散分配 | 87.885 | 1.7993 |
| 同价K残差 | 88.576 | 1.7993 |

这些结果支持在当前底座上把余量投向V，而非直接沿用“K永远更重要”。V方案相对原底座点改善3.54pp，相对Base2少约20%字节、点分数高1.81pp；与Native4仍差1.31pp。原底座对比的文档级配对区间为[1.34,6.13]pp，但广泛探索校正后尚非确认性证据，需由新源文档检验。[配对结果](../results/round5_v1/development64_strong_analysis/comparisons.csv)

这里的预算交换具有明确含义：每个选中单元增加每元素一位符号和每token一个幅度，未选单元不保存这份残差。因此改善对应的是有限存储买到的覆盖，而非先存下全精度再决定读取。比较随机、分散和K残差时保留同样的表示与完整成本，使“额外精度存在”和“精度投在哪里”成为可分开的研究问题。

首16图曾给出V方案95.67、底座92.58、分散94.01、随机92.76、K残差92.78。扩到64图后整体分数与排序差距均变化，说明不能把最初+3.09pp当作可直接外推的效果量。[首16图结果](../results/round5_v1/sparse_dev16_analysis/summary.json)

## 二、组合有效，尚不能归功于新排名

同码同预算下，head梯度排序90.537、细粒度梯度90.651，接近有限输出收益90.771；普通MSE排序89.749、相对输出误差90.187。现有数据允许说输出/损失相关分配值得用，尚不支持新排序优于强梯度基线。梯度对照使用Full自生答案的pooled CE，是RateQuant策略移植，不是其原论文完整复现。[强分配对照](../results/round5_v1/development64_strong_analysis/summary.json)

更严格的匹配交换也没有给出正证据：在ΔMSE接近、相同24个残差单位的两臂中，高预测收益组88.989，低组89.477。该结果保留，不能据它宣称已将“重构误差”与“有用精度”因果分开。V分组、视觉bias和K均值修正在完整64图也没有明显改善，G1/G8及bias四臂均约87.24–87.49，两个mean臂均为87.230。[功能修复对照](../results/round5_v1/functional_dev64_analysis/summary.json)

这些结果把下一步问题缩小到：怎样预测有限精度在真实学生状态里的价值。单元交换没有兑现局部收益的排序，提示需要区分单元间交互、参考状态与学生状态；有效的缓存组合已经成立，估计器仍有改进空间。

联合K/V没有自动胜过简单V方案：finite混合89.689，gradient混合90.868。进一步纳入局部交互的DP为89.471，singleton为89.689；conditional greedy与DP在49个预算策略行上相同，已去重。局部目标优化更好没有转成更好的最终答案，这限制了“更精确求解即更好方法”的叙述。[混合结果](../results/round5_v1/mixed_dev64_analysis/summary.json)、[策略结果](../results/round5_v1/policy_dev64_analysis/summary.json)、[局部交互目标](../results/round5_v1/interaction_policies/summary.json)

## 三、机制发现及其适用范围

cal16的同q局部输出误差能量，V约25.44万、K约10.47万；V残差rank-2平均只解释约7.1%。这些量支持探索V精化，也让“少量低秩系数即可修好V”的押注降级；它们仍是冻结query条件下的局部观察，不等于跨轮因果损失。[T0统计](../results/round5_v1/t0_summary.json)

把K、V先转到共同的局部输出误差单位后，Gaussian联合率失真参考也偏向给V更多payload。但它假设误差协方差、局部线性化及可分配连续位宽，未包含真实码本、元数据和跨层反馈。因此，它提供设计方向，不能直接给出现有PQ与符号码的最优配置，更不能替代自由答案验证。[统一度量的联合参考](../results/round5_v1/joint_rate/summary.json)

谱能量同样不能直接预测答案。query-r16自由答案仅24.82，恢复范数后36.90；r32由83.42升至89.90，仍未超过当前PQ。它们含材料化重构与基矩阵，不能把假想payload当作真实≤1.8bit结果。[范数干预](../results/round5_v1/norm_dev16_analysis/summary.json)

固定Full-q、同一校准V1与文本缓存的控制揭示了代理的边界：问题prefill时，r16的score MSE为0.569，小于PQ的0.737，但联合读出相对MSE为0.120对0.089；decode时其score MSE已高于PQ。恢复范数虽改善自由答案，却使固定Full-q局部误差进一步增大。由此，prefill/decode、分数形状、视觉/文本mass及学生q分布成为后续机制实验要拆开的变量。本控制采首问题末prefill与若干decode位置，用于定位局部读出与完整模型结果的差别。[同q分层控制](../results/round5_v1/fixed_query/development16/summary.json)

## 四、最后一组编码试验后冻结

最后一组编码试验已经完成：将K增益从FP16压到g128的8/4bit，回收幅度槽字节再买V残差。设计账分别省约0.0303/0.0459bit，允许多约6/9个V单元；但完整开发64图上分别为90.699与90.339，未超过原V方案90.771或Mixed-grad90.868。它说明幅度槽仍能压紧，却没有给出新质量优势。因此保留预先冻结的主候选，结束本轮编码搜索，不据此增开优化器。[gain完整结果](../results/round5_v1/gain_dev64_analysis/summary.json)

论文定位应尊重已有组件：[RateQuant](https://arxiv.org/html/2605.06675v2)已有梯度/率失真分配，[KVTuner](https://arxiv.org/html/2502.04420v1)已有输出误差引导搜索，[HeadQ](https://arxiv.org/html/2605.03562v1)已有模型可见失真，[CalibQuant](https://arxiv.org/html/2502.14882v2)已有视觉低bit校准，[TurboQuant](https://arxiv.org/html/2504.19874v1)已有符号残差组合。我们应检验视觉极低bit条件下，表示、残差形式与预算价值如何共同决定可执行前沿；当前可交付的是这一组合及其正负证据，尚非普遍最优规则。

## 五、全新Doc64确认：相对Base2的优势得到独立验证

新64份文档、256问已完成。冻结主候选Mixed-grad为91.445@1.79942bit，Base2为87.818@2.25223bit；文档级配对改善3.627pp，95%CI[0.868,6.466]pp，预定三个主比较的Holm p=0.02436。相对原底座86.286改善5.159pp，Holm p=0.00123；完整预算逐图满足≤1.8bit。以上是新源确认结论，与开发集点排序分开。[确认主比较与预算审计](../results/round5_v1/doc_confirmation_summary/summary.json)

Native4为93.495，主候选差−2.050pp，区间[−4.654,0.021]pp；0.5pp点目标与区间非劣均未达。不能因区间跨零宣称两者等价。主候选也不是纯V有限收益排序，当前正证据支持的是冻结混合梯度策略与实际低比特表示的组合。[开发与确认资源—质量图](../figures/round5_final/doc_resource_quality_two_cohorts.png)

## 六、新鲜Text64迁移：底座点分数改善，排序发生变化

在64张新图、每图一问上，以Doc冻结参数直接迁移且不做Text校准。官方TextVQA软准确率：主候选72.969、原底座68.281、纯V有限收益74.688、Base2 75.469，Full与Native4均78.594。主候选相对底座点改善4.688pp，但未达到Base2；不能把Doc上的优势无条件外推到场景文本。[官方指标与图像级区间](../results/round5_v1/text_confirm64_analysis/summary.json)

纯V方案在此池高于冻结主候选，是跨域排序变化的观察；不能事后改主候选，更不能据64图断言“某任务因果最优就是纯V”。外效度仍是单模型跨域，非多模型结论。[Text64迁移图](../figures/round5_final/text_transfer_official_score.png)

选择协议从3166份官方源图中排除既有记录的897图并集，在剩余源上按固定hash取64图、每图固定一问，不按答案类型或压缩掉分挑选。这个池用于回答文档上形成的精度策略能否转移到场景文本，而非替代完整5000问基准。[来源选择脚本](../code/a2/stage_round5_text64.py)

固定Full-q、V1和文本状态的机制图作为独立局部证据保留，不把其散点当作最终答案预测。[prefill/decode机制图](../figures/round5_final/fixed_full_query_phase_mechanism.png)

## 七、真实系统收益与现有耗时

同输出控制已完成：3张固定开发图、7个方法、每题相同8个输出ID，63次测量和21次预热；各试次核验输出ID、逻辑位置和GPU安静状态。端到端会话中位数：Full2070.0ms、Native42139.7ms、Base22121.7ms、原底座2309.0ms、主候选2358.2ms、V202310.2ms、纯V满预算2330.1ms。主候选比Base2约慢11.1%；编码中位数139.6ms对56.1ms。这组结果确认了完整模型路径的实际代价，当前优势是存储与质量，时延尚未占优。[固定输出计时与原始试次](../results/round5_v1/quiet_timing_analysis/summary.json)

新Doc确认的主候选比Base2少20.1%视觉KV字节、ANLS高3.63pp；较省的V20约1.67956bit，比Base2少25.4%字节，ANLS为88.998对87.818。预算包含实际视觉编码、位置及规定encoder常量，文本KV仍为FP16；模型权重和峰值显存另计。逻辑读账与固定输出时间分别保存，当前没有物理HBM流量测量。

下一阶段值得优先研究的是表示固定后、真实模型状态如何改变精度的价值，并以新域或第二模型检验分配的迁移。已有结果为这条路线提供了独立的新文档正证据，也给出了局部代理、跨域迁移与运行成本的具体改进方向。
