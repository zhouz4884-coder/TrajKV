# 当前实际目标：一比特视觉 KV 的可修复失效

2026-11-13 已通过目标工具建立新的 active goal；旧目标由用户清除，不冒记为完成。本文件对应实际目标，取代 v3 中预设的码率区间。原始理论和外部讨论文件保留。

研究问题：同样的一比特格式，编码电平、径向幅度、角度和文本状态形成分别改变多少端到端质量？哪些修复能以真实成本换回质量？

主要证据来自双 RTX3090 上的完整 InternVL3-8B（Qwen2 语言骨干、4 KV heads）和实际 packed KV 自由生成。编码电平采用同轴、同 g128 的 min/max、sign、MAD、Lloyd 对照；用真实量化范数×真实/量化方向的四臂分离径向与方向；增益比较中心化最小二乘、原点范数匹配、跨 KV-head 共享。分段温度和问题状态形成作为机制诊断。

先完成100张独立开发图像、每图一题；在这些开发结果上冻结候选、同分辨率强质量参考、参数、代码和比较，再运行保留的新64图（最多6轮）。确认集在本周期与开发图像不重叠。质量目标仍是距冻结参考≤0.5pp；不能把开发样本下接近当成已证明非劣。

在已测候选中求满足固定质量要求的最低**实际**视觉 KV 存储，计入元数据、增益、位置和辅助所有权。1.25、1.31、1.09 都是待测成本点；不预设最优码率或普适 SNR 门槛。报告 ANLS、exact、参考答案 log-prob、FP16-logit KL、同步耗时和资源账。K2/V1、1.8-bit 方案及固定存储读取保留为对照与回退。

交付是经实验支持的机制、资源—质量前沿、可复跑结果和适合论文的论证；论文以洞察组织，实际实现支撑其证据。

## 已出现的新证据，非预设结论

100图范数×方向诊断：MAD A00/A10/A01/A11 的 ANLS 依次约49.48/67.30/86.31/86.67；Lloyd 为54.93/66.23/88.69/86.67。A10恢复真实范数，A01恢复真实方向，另一半视觉V严格FP16。这否定当前数据上“范数独占缺口”的预测；方向恢复的收益更大。四臂均是持有FP16的oracle诊断，不进入低比特存储前沿。

100图联合真实packed MAD K1/V1：无增益33.53，中心化每KV-head LS增益43.27，共享增益37.46；min/max K1/V1为0，K2/V1为65.53，K2/V2为85.60，FP16为86.67。说明部分失效确实可修，但不能宣称已在1.31bit追平2-bit。连续logit KL也从min/max联合的9.85降到MAD的1.86、MAD+LS的1.40，故不只是ANLS台阶。
