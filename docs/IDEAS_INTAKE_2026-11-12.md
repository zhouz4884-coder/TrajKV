# 外部建议吸收与本轮实验对应

本文件记录用户补充想法的采用方式。外部文本中的肯定表述作为待测假设，不替代真实结果。

| 建议 | 本轮对应 | 判断 |
|---|---|---|
| 中层 base / base+residual 双读，当前步升级后续层 | `self_probe.py` + `bank.read`；与 margin、均匀、周期同预算比较 | 新增可运行原型；探针两读和同步均计费；信号是残差纠偏幅度，不是已知 FP16 误差 |
| 事实载体 K/V 单位置手术 | `carrier_surgery.py`、幅度匹配的 `carrier_surgery_v2.py` | 单位置和词 span、K/V 分开、剂量与局部反例全部保留；不预设 K 主导或 V 不传播 |
| 轮间局部状态修复 | 同文本参考状态手术作为诊断；`repair_once` 作为实际重算原型 | 参考切片不能当零成本在线算法；原位置的多层依赖和实际重算开销需要实测 |
| 描述后追问的桥接协议 | `clevr_bridge_dev32_runner.json` 与 `--hide-visual-after-description` | 单列人为历史通道压力测试，与原生十轮问答分开；描述轮不评分 |
| 双口径资源账本 | canonical `bytes.py`、owned、read_events、peak_allocated、TTFT/解码时间 | 真实 packed 常驻与临时物化分开；逻辑 payload 不是实测 HBM 带宽 |
| 强基线算子级移植 | 锁定官方 KVarN 数值函数与源码 SHA | 明确 mechanism-port；质量共用骨干/执行器；物化参考不冒充 packed 服务效率 |

## 直接修正的解释

- 同 token、相同当前读取条件下，参考重编码若救回未来质量，支持数值历史状态路径；不能反向解释成只有文本错误。
- 大 margin 没有参考扰动界时不保证 argmax 不变；相同 token 也不保证 KV 状态相同。
- K 改变注意力归一化，V 的偏差同样能经后续层与新状态传播。实际比较长期影响，不能由局部公式推出复利必然性。
- 自回归当前 logits 决定下一 token，当前写入的 KV 属于刚消费的输入 token。前驱重算与载体状态写入已作为不同策略实现。
- 中层触发只改善其输出及后续层状态，前面层已经写入的 KV 不会自动被修正。
- 少数位置的恢复比例是实验量，不是定理；功能词及短答案也可能携带指代与视觉信息。
- 静态渐进表示与 query 级读取双预算已有 ReadKV，本文不把资源轴本身当原创。

## 本轮迭代记录

第一轮随机位置对照经实测发现经常落在 ref/base 完全相同的共享前缀。V2 明确排除零差异位置，按 K/V 各自的实际扰动幅度匹配。第一次粗粒度状态修复少算了多次 replay 的基底和文本读取，原结果保留并标为超预算排除；后续版本逐调用记账并重新验证。
