# 第六阶段之后：仪器、账本与三个可开工的动作

日期：2026-11-16。只读 `results/round6_v1/` 与 `results/round5_v1/`，跑 0 GPU，不改任何冻结产物。

---

## 0. 一句话

**第六阶段不是"方法没打赢"，是"这台仪器量不出 2pp 以下的任何差别"。** 在它能量的尺度上（≥4pp），本轮所有 8 个策略完全不可分；而在它能量的尺度之外，本轮唯一声称的机制（排序）在换一批源图后从 **+4.44pp 变成 +0.06pp**。

所以下一步真正该做的不是第七个分配策略，是**先造出一台能读 0.3pp 的仪器**，再谈方法。

## 1. 决定性数字：仪器分辨率

从 `results/round6_v1/doc_confirmation_analysis/scores.csv`（205 题 / 54 源文档）自己重算的**源文档聚类配对 bootstrap**（4000 次）：

| 配对 | Δ | 95% CI |
|---|---:|---:|
| incumbent − full8 | +1.38 | [−2.60, +5.47] |
| RD − full8 | +1.90 | [−1.45, +5.56] |
| v_impact_max − full8 | +1.56 | [−2.62, +6.22] |
| v_pair − full8 | +0.06 | [−2.96, +3.36] |
| native4 − full8 | −1.06 | [−3.04, +0.76] |
| base2 − full8 | −3.46 | [−6.51, −0.36] |
| **RD − spread**（同臂数随机放置） | **+1.90** | **[+0.30, +3.75]** |

半宽 **2.6–4.0pp**。本轮 8 个策略的点估计全距是 **1.86pp**（88.10 → 89.95）。

**结论：这一轮里 8 个策略的任何排序都在一台 ±3pp 的仪器上读出来的 1.9pp 噪声。** 只有 base2 输给 FP16（−3.46pp）和 RD 赢随机放置（+1.90pp）两条显著。

顺带一个方法论上要写进报告的细节：`v_pair−incumbent` 的 CI 是 [−3.92,+0.83]，而 `v_pair−spread` 是 [−2.64,+2.58]。**同一个方法，对不同基线的区间宽度差 1.3pp**，因为 spread 与 pair 在同批题目上更相关。这说明配对设计比样本量更影响分辨率——这正是下面 D1 的根据。

## 3. 从字节账推断：残差只剩 12%，且已经过了拐点

`depth_doc64_mechanism/byte_audit.json` 单条记录的 owner 分解（N=1792，44 stages，1.79998 bit/KV scalar）：

| 项 | 字节 | bit/KV scalar |
|---|---:|---:|
| `visual_base` | 10,123,264 | **1.5762** |
| 其中纯 payload (K2+V1) | — | 1.5000 |
| 其中 scale 元数据 | — | **0.0762** |
| `visual_residual`（44 × 18N） | 1,419,264 | **0.2210** |
| `visual_position` | 14,336 | 0.0022 |
| `selector_metadata` | 1,792 | 0.0003 |
| **合计** | 11,560,453 | 1.7995 |

**残差预算只占总预算的 12.3%。** 这句话有两个方向的后果：

**(a) 坏消息：所有"残差怎么分配"的研究，理论上限是 12%。** 即使把残差部分的损失全部消掉，也只在残差那一段换收益。而这一段的价值实测如下（`depth_curve_dev16_analysis`，16 图 62 题，同人群同配置只改预算）：

| 预算 | ANLS (pair) | 相对上一档 |
|---|---:|---:|
| 1.700 bit | 94.57 | — |
| 1.750 bit | 94.75 | **+0.18pp / +10 stages** |
| 1.800 bit | — | 外推 ≈ +0.2pp |

**0.05 bit（=10 个 stage）= +0.18pp，即 0.018pp/stage。** 注意 62 题上一道题翻转值 1.6pp，所以这个 +0.18pp 是若干题的 ANLS 部分分漂移，不是"多对了几道"——**它已经在指标的粒度以下。**

作为上界参照：base2（0 残差，2.25 bit）→ incumbent（44 残差，1.80 bit）在 Doc54 上是 84.59 → 89.43 = +4.84pp。这条不是同字节对照（两者 V 的 base 位宽不同），只能说明"44 个 stage 的量级是几个 pp"，不能除以 44 当作每 stage 的价格。真正同字节同格式的增量只有上面那条 +0.18pp / 10 stage。

同一条曲线上，前几个 stage 值 0.11pp，第 34–44 个 stage 值 0.018pp，差 **6 倍**。**你们已经站在拐点右侧的平地上。** 平坦意味着两件事：加 stage 几乎不涨分（D3 的账），换位置完全不涨分（§2 的实测）。**"分配"这个动作的收益上限，就是这台仪器现在读不出来的那 0.3pp。**

**(b) 好消息：88% 的预算在 base 里，而 base 的编码从来没做过阶梯。** 卷三/第五轮做过的是 **1-bit 的 K 阶梯**（RTN 0.00 / sign 28.00 / MAD 56.76 / Lloyd 62.98 / 2bit 94.29，同 1.25 bit），横跨 **63pp**；**2-bit base 的阶梯一次都没做过**，而 2-bit 的 K base 是现在的 88% 主体。同一个比特数下换重构规则能值 63pp，这条经验目前只被用在一个不在预算里的轴上。

## 4. 一个可推导的量，解释了为什么"K 深度"和"V 深度"行为不同

每一级残差是"符号位 + 每 token 一个 FP16 幅度 $\alpha$"，而 $\alpha^*=\mathbb E|r|$ 正是 1-bit 最优电平。于是

$$D_{n+1}/D_n = 1-\frac{(\mathbb E|r|)^2}{\sigma_r^2} = 1-\rho^2,\qquad \rho\equiv \frac{\mathbb E|r|}{\sigma_r}$$

**这是纯形状统计量，与幅度、与层、与数据集大小都无关。** 高斯分布 $\rho=\sqrt{2/\pi}=0.7979$，给出 $1-2/\pi=\mathbf{0.36338}$。

实测（`depth_rd_fit/curves.json`，cal16 全 112 单元）：

| 轴 | $D_2/D_1$ | 反推 $\rho$ | 与高斯之差 |
|---|---:|---:|---:|
| **K** | **0.363459** | 0.7978 | **−0.0001（四位小数吻合）** |
| V | 0.415065（cal16）/ 0.404223（实存流） | 0.765 / 0.772 | −0.033 / −0.026 |

三件事由此可以直接推出来，不需要跑答案：

1. **K 的残差精确是高斯**，所以在 K 上加一级符号位是**信息论意义下的最优 1-bit 编码**，没有可改进空间。K 深度"能迁移"是因为它的编解码本来就没有浪费。
2. **V 的残差不是高斯**（$\rho$ 低 3–4%，说明重尾/结构化），符号位在 V 上每级多留 10% 误差。**"给 V 加深度"这件事，从编码效率上说本来就该比 K 差。** 这解释了 §2 的反转方向：RD（K 为主加深）在 Doc54 上赢，Pair（只给 V 加深）输——不是运气，是 $\rho$ 的差。
3. **两级符号格式被自己支配。** 两级符号 = 2×1.125 = **2.25 bit/elem**，实测 $D_2/D_0$：K 0.1277、V 0.1361。单个 4 电平级（符号位 + 幅度位 + 共用 FP16 scale）= **2.125 bit/elem**，高斯下 Lloyd 4 电平 $D=0.1174\sigma^2$。**所以对每个 depth-2 的单元，现在的格式多花 0.125 bit 还多留 8%（K）/14%（V）的误差。** 这是纯粹被支配，不是权衡。

必须同时说清这点收益的量级：残差只占 12.3%，8–14% 的残差改善 ≈ 0.02–0.03 bit 等效 ≈ **0.03–0.05pp**。它是免费的，但不是救命药。**写进论文可以，当作主结果是自欺。**

## 5. 元数据里可能藏着 6–10 个 stage

`visual_base` 是 1.5762 而不是 1.5000，多出 **0.0762 bit/scalar = 2,182 bit/token**。按算术最像：

- V 的 **per-token FP16 scale**：112 单元 × 16 bit = **1,792 bit/token**
- K 的整图 per-channel FP16 scale+min：112 × 128 × 32 / 1792 ≈ 256 bit/token
- 余下 ≈ 134 bit/token

若这个分解成立（需从编码器源码核一行），**单是 V 的 per-token scale 就吃掉总预算的 3.5%**，是残差预算（0.221）的 **28%**。改成 fp8 回收 0.031 bit（≈6 stage），改成"同层 4 个 KV head 共享一个 scale"回收 0.047 bit（≈9 stage）。

对照 §3 的剂量曲线（0.018pp/stage），6–10 个 stage ≈ **+0.11–0.18pp**。仍然小。但它是**单调加分、不可能反向**的动作，而且方向恰好是第六阶段自己建议的"保覆盖"。

## 6. 我认为真正该做的三件事

### D1（1 小时 GPU，最高杠杆）：把 ANLS 换成连续量，先把仪器造出来

**现在 100% 的争论都卡在"±3pp 读不出 1.9pp"。** 换指标就解决了，不用换方法。

做法：对 round6 已有的 8 臂 × 205 题，用**同一串参考答案 token**做 teacher forcing，每题取

$$L=\frac1{|a|}\sum_{t}\log p_\theta(a_t\mid \text{image},\text{question},a_{<t}),\qquad \Delta=\text{第 1 个答案 token 的 } z_{(1)}-z_{(2)}$$

$L$ 是连续量，$\Delta$ 是"离悬崖多远"。总成本 1,640 次 prefill（$|a|\approx4$ token），两卡约 1 小时，**零新数据、零新方法、不动冻结产物**。

三条即刻可读的结论：

1. **$L$ 与 ANLS 的相关**：8 个臂做回归。若 $r^2>0.7$，$L$ 就是 ANLS 的有效代理，后面所有比较都可以在 $L$ 上做。
2. **分辨率**：同一个配对用 $L$ 重算，看 CI 半宽能否从 ±3pp 掉到 ±0.3pp。这是唯一能把"分配无用"从猜测变成**上界**（$|$效应$|<0.5$pp）的东西。
3. **逐题分解**：205 题 × 8 臂 × 44 单元的扰动，可以做成回归。**44 个单元的价值变成 205×44 个观测，而不是 205 个。** 这才是"从 63pp 那类效应里学规则"的正确样本量。

### D2（半天）：2-bit base 的编码阶梯 + 4 电平残差级

两件都改编码器、都不改内核结构：

- **2-bit base 阶梯**：同 2.25 bit，K base 换 5 种重构——现 4-dim product VQ（256 码字）/ 标量 Lloyd 4 电平 / 2-dim VQ(4 码字) / per-channel 4 电平 / RTN（负对照）。20 图 62 题。判据：最好者比现 product VQ 高 **≥1.5pp**（用 D1 的 $L$ 读，CI 会小一个量级）。**base 占 88% 预算，而 1-bit 阶梯里同比特换规则值 63pp——这是唯一还留着的数量级。**
- **4 电平残差级**：把 depth-2 的两级符号换成一级 `{±1,±3}·α`（多一个幅度位、共用 scale）。免费 −0.125 bit、−8%（K）/−14%（V）误差，且**只改编码器，reader 把两级加法合成一次**，是 §4 的直接落地。

### D3（20 分钟，无 GPU）：把 6 道受害题逐题分型

`ERROR_HETEROGENEITY` §2 已经把案例列出来了：`1966 → 1970-1974`（读到页面上**另一个日期区间**）、`Agenda → Agenda for a meeting`（输出扩展）、`577 → 其他金额`。这三类需要的修法完全不同：

| 分型 | 判据 | 需要什么 |
|---|---|---|
| **路由错**（读到别处） | prediction 在页面全文中另有出处，且与参考区域不同 | K 的路由精度，或加覆盖；**加 V 位宽无用** |
| **读数错**（同位置读错字） | prediction 与该区域文本近似但字符错 | V 位宽 / 4 电平级 |
| **格式/扩展** | prediction ⊃ 参考 | 与 KV 精度无关，是指令/解码问题，**不属于本论文** |

这 20 分钟决定 D2 的两件事该往哪边投，也决定论文里"误差出口"这段能不能写。**如果 6 道里 4 道是格式问题，那本轮的 −1.33pp 有一半根本不是 KV 精度造成的**，这本身就是必须先知道的事。

## 7. 我建议论文改写成什么

现在这条路（"我们的分配器更好"）在三批人群上给出 +4.44 / +0.06 / −1.33，**不可写**。可以写的是三句话，每句都有自家数据、都不依赖"比别人强"：

1. **一个负的、带界的结论**：在 ~1.8 bit、8 个横跨深度/覆盖/轴/排序的策略上，DocVQA 的差异全距 1.86pp 而配对 CI 半宽 3ppt；因此**在这个工作点，精度放置不是瓶颈**，瓶颈在 base 表示与证据路由。这不是"我们没做好"，这是"这个子问题被关闭了"，而且是用带区间的数据关闭的。
2. **一个可推导的量**：符号级残差的效率 $1-\rho^2$，K 实测 0.36346 与高斯的 $1-2/\pi$ 四位吻合，V 偏离 3–4% ⇒ **K 该加深、V 该加分辨率（4 电平），而"给 V 加深"是编码层面就次优的选择**。这条把第六阶段的反转从"玄学"变成"参数"，任何人拿自己的数据算 $\rho$ 就能检验。
3. **一个资源结论**：1.8 bit = fp16 视觉 KV 的 11.2%（`packed_visual_ratio` 0.11232），Doc54 上与 FP16 点估计持平（+0.06~+1.90pp，CI 跨零）；且**残差只占预算 12.3%、边际 stage 值 0.018pp**——这是"低比特视觉 KV 的收益已经饱和"的定量证据。

第 2 条是唯一有正面机制的部分，第 1 条是唯一能被别人引用为"别再往这儿投入"的部分。**要让论文有"效果"，必须靠 D1+D2 把仪器磨到 0.3pp，再在 base 上找那 1.5pp——不是继续搬残差。**
