# Round6 对照与文献定位

2026-11-15直接核对原始来源。

- [RateQuant](https://arxiv.org/abs/2605.06675)：按量化器实测率失真关系，再按敏感度分配位宽。本轮实现的是同一TrajKV码流上的策略移植：cal16实测D(0/1/2)，复用统一尺度CE敏感度，带级间前置约束的等成本贪心；不是完整官方复现。用来挑战深度选择，而不把固定Gaussian衰减当强对照。
- [ReadKV](https://arxiv.org/abs/2610.11245)：渐进码与保留/读取两个预算已有先例。本轮测试未选残差不存的静态存储配置；没有把查询时自适应读取归为新贡献，也不拿逻辑读取账直接认领HBM吞吐收益。
- [KIVI](https://arxiv.org/abs/2402.02750)：K per-channel、V per-token是其核心结构发现。本项目Native2/4控制是视觉段量化、文本仍FP16的同模型控制，不是压全部KV并保留滑窗的官方整系统成绩。

当前待检验的具体组合是：真实PQ键方向基码、整图双质心值基码、少量两级残差，在相同完整存储帽内交换精度深度与覆盖。是否有价值由新源自由回答与同输出代价决定；组件有先例不自动否定组合，也不能仅凭拼接声称创新。
