# Round7的方法与比较口径

本阶段研究两个问题：不增加同一码流的索引宽度，重新选择码字和幅度能否改善自由回答；缩小基础码本后，把释放的预算用于残差覆盖，能否移动完整存储前沿。实现入口是 `code/a2/round7_runner.py`，真实图像经过完整FP16模型，视觉边界后使用packed KV继续自由生成。校准诊断和固定输出计时另行标注。

## 表示与同格式编码

每层、每KV-head先存视觉K的FP16均值，去均值后做归一化Walsh–Hadamard变换。每个128维向量拆成32个4维块。G4_256使用32个uint8索引；G4_16把两个4bit索引装入一个byte，实际为16字节，而非用uint8数组冒充1bit/元素。两者都保留一个FP16行增益。当前16项码本由固定Gaussian样本拟合；旧head factor数值显式继承，并用新文件绑定新码本hash，没有宣称重新做过模型校准。

V使用整图per-channel双质心1bit码，保留所有视觉token的基础支持。K残差在旋转坐标中编码，V残差在原坐标中编码。每级残差为每token的128个sign位和一个FP16幅度，共18N字节；若有第二级，按第一级的实际FP16重构重新求残差。部署只持有所选残差池，不持有原始FP16视觉K/V。

同索引宽度的开发臂包括：原norm增益、LS幅度提议、实际FP16重构下的块坐标重选码，以及rank-one query度量重选码。幅度还试验了projection规则；这些分支分别比较，没有把它们全部堆到一个候选上。LS提议之后仍有冻结head factor折叠及FP16舍入，因此不能称为整个部署表示的精确全局LS最优。

query度量采自压缩学生状态的8个校准源、末prefill和最多两个decode query；按GQA实际归组，使用未减query均值的二阶矩。rank-one近似额外保存FP16方向和FP32系数，在InternVL上增加29,120字节，计入完整预算。它是query乘积代理，不是末端任务Hessian；ρ只用于诊断。保留原始参考K的采集器不具有低比特部署资格。

## 覆盖与预算交换

控制实验让incumbent、spread和random使用同一个depth reader、全一级残差、同lookup/ranking/policy长度及相同完整字节。编码实验再分别检查：固定残差集合时降低K索引位宽；在同1.8bit完整上限下重新使用剩余预算。

成对交换在校准阶段真实执行撤去一个级、增加另一个级以及联合交换。每个干预和每种目标都重新构造干净cache与压缩bank，重放完整问题后缀及固定目标历史。移除单动作把stage上限设为k−1，禁止冷位自动补入；添加单动作使用k+1，只作校准诊断，必要时放宽一个stage的预算；联合交换保持k及原部署上限。完整224项排序始终计448字节，policy descriptor计5字节，不能因单动作改变排名表长度。

GT目标为固定首参考加EOS；Full自目标为同一冻结Full模型最多4个自生成token，遇stop可提前结束，不强行补EOS。每问先平均目标token NLL，再按来源内问题、数据集内来源及两个数据集等权汇总。K2使用原Text首标注，K1目标消融使用预先固定的normalized-plurality首参考，因此两路线GT NLL绝对值不直接比较。它使用cached image prefix加速，属于真实packed模型诊断，不是自由生成准确率或端到端延迟。

比较独立分数相加、整对静态分数、分批接受后重估。当前候选池下，匹配“每批最多一对”的选择约束后，初态静态分数能够复现分批重估的最终policy。因此本阶段不能把该policy的质量增量单独归因于反馈重估。精确等价对照及别名另外登记，复用同一真实执行结果，不复制成额外独立样本。

正式8对候选分为4批。每方法逻辑前向上限为`2×4+3×8+1=33`个allocation评价；14问同时评分GT/self对应924次packed后缀前向。实际跨方法共享相同输入，K2共1,372次、K1每个目标选择run共1,400次；这些计数不含Full原生目标采集，不能称为相同物理时间或端到端校准成本。匹配分批约束的静态加和与静态整对分别只需16个singleton或8个joint及一个共同baseline，即可形成相同最终策略。

最终部署policy在确认前冻结。K2分支保存完整224项一级排序，随实际N和完整1.8bit上限选取可负担前缀，并非所有图像使用同一个固定集合或stage数；K1联合分支则显式限定43个级，释放的基础索引字节直接体现为更低总存储。不同N下其完整bit略有变化，“约1.3bit”不是每图严格不超过1.3000的承诺。部署读取全部保留级；逻辑读取字节、实际owner与固定输出时间分别报告。

## 完整字节与两个骨干

对L层、H个KV-head、N个视觉token、D=128，完整视觉账包括packed K/V、K均值/增益、V质心、码本、位置、残差池、lookup、排序、policy及encoder参数。总bit为8B/(2LHND)。每个实际session都从真实owner独立复核，不再叠加已经汇总过的`total_unique`。

主骨干为InternVL3-8B-hf，28层、4个KV-head。第二骨干为原生FP16 LLaVA-v1.6-vicuna-7b-hf，32层、32个KV-head，使用独立identity因素和固定排序。其视觉N不必整除32，V只在最后一个物理bit word保留必要尾部空间并计费；语义视觉token和位置没有补齐。第二骨干的64源首问确认与主骨干Doc128共享其中64个来源，不增加独立来源总数。

## 数据、质量与成本

旧Doc64和已观察Text64用于开发。新的策略选择集对本次拟合留出来源，但Doc选择源曾参与旧基码factor校准，不能称全项目从未使用。交换校准实际使用4个Doc源与4个Text源，共14问；已准备的更大训练池不等于全部已经拟合。

主确认在方法冻结后物化，使用新Doc128源/412问及Text128源/128问。Doc来自额外官方train分片，按历史来源及图像内容排重，称project-fresh，不声称基础模型预训练绝对未见。Text保留官方10答案评分；低共识首答案的修正只作用于校准目标，评测答案multiset和官方分数不变。

主质量是自由生成后的Doc ANLS和Text官方soft accuracy；按完整来源做配对bootstrap及sign flip，所有报告比较的Holm范围保留。连续损失、margin、teacher argmax和熵均属于诊断。固定输出计时使用独立schema，六方法、三旧开发源、每源一次warmup和三次测量，逐trial核对输出ID、逻辑位置及双GPU空闲；不把固定输出实验评分成自由回答质量。
