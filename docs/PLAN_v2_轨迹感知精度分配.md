## 0. 与 v1.0 的差别（一句话）

v1.0 问的是"**K 和 V 该各分几位**"，v2.0 问的是"**在未来查询未知、状态持续复用的条件下，有限的表示精度该保护什么**"。前者是一个配置问题，后者才是一个科学问题。

| 维度 | v1.0（ARP） | v2.0（TrajKV） |
|---|---|---|
| 优化对象 | 单轮平均注意力失真 | 轨迹上的失真分布（含尾部）与历史介导误差 |
| 时间视角 | 静态：标定一次，全程用 | 动态：t=1 的最优是否在 t≥2 失效 |
| 核心风险 | 与 KVTuner/AATC 撞车 | 必须证明"平均失真目标无法捕获的轨迹效应" |
| 证据起点 | 直接跑 E1 主表 | 先做 P0 审计 + P1 机制，再决定是否开发方法 |
| 失败代价 | 跑完 3000 题才发现没优势 | P1 阶段（约 4 GPU-days）即可判定方向 |
| 数学基础 | 有错（见 ERRATA E1） | 修正后的一阶分解，且给出可证伪预言 |

### 1.2 未充分验证（当前**不能**写进论文主张）

- "非对称比对称好"：n=36，差 3 题，CI 约 ±12pp，只能当效应量先验。
- "阶段分离有独立贡献"：从未做过固定存储、只变读取的干净消融。
- "注意力 MSE 能预测答案质量"：反例已出现（`aligned` 的 attention_error 比 `asym_sign` 低 43%，correct 却低 1 题；见 ERRATA 附录）。
- "24.61% 是稳态存储比"：实际是 base+refine 的物化口径，**不是**驻留口径。

### 1.3 待验证（本项目的真正目标）

- **H-A**：按当前轮/标定分布选出的精度配置，在未来轮次会系统性失效，且失效可预测。
- **H-B**：视觉 KV 误差会经由当前轮生成的文本状态传播到后续轮，形成独立于"直接读取误差"的第二条通路。

这两条若成立，才有资格谈"新方法"；若不成立，诚实地报告"没有轨迹效应"，本项目转为测量论文或直接终止。

## 2. 核心问题与两个假设

### 2.1 一句话

> 多轮视觉 KV 的精度损失，是否存在**传统平均失真目标捕获不到的轨迹效应**？若存在，能否用训练无关的方法降低它？

### 2.2 两个假设的可观测形式

**H-A（敏感性漂移）**

设 $\mathcal S_t(l,h,\text{axis})$ 为第 $t$ 轮对某 (层, 头, 张量) 注入单位扰动所引起的输出失真（敏感度）。则 H-A 断言：

$$
\rho\Big(\operatorname{rank}\mathcal S_1,\ \operatorname{rank}\mathcal S_{t\ge2}\Big) \ll 1
$$

判据：跨轮 Spearman $\rho < 0.5$，且"用 $t=1$ 排序分配"在 $t\ge2$ 上的 regret 分布存在厚尾（$\mathrm{CVaR}_{0.9}$ 显著高于按 $t\ge2$ 排序的下界）。

**H-B（历史介导）**

$$
\text{Visual KV error}\ \longrightarrow\ \text{Text-state deviation at turn }t\ \longrightarrow\ \text{Error at turn }t{+}1
$$

判据：在**固定 token ID、固定位置、固定当前读取条件**的前提下，仅替换上一轮的历史 KV 分支，仍能产生可测的 $\Delta$logit 与 $\Delta$EM；且该效应量不小于直接读取误差的某个可辨比例（比例阈值由 P1-D 定，不预设）。

> 注意：H-A 与 H-B 不是同一件事。H-A 是"配置选错了对象"，H-B 是"误差有第二条传播路径"。前者可以用更好的分配解决，后者不能。

### 2.3 为什么这两条比"K/V 各几位"更有辨识度

| 已有工作 | 它优化什么 | 我们要多证明什么 |
|---|---|---|
| KIVI (ICML'24) | K per-channel / V per-token 的非对称量化 | 不涉及跨轮 |
| KVTuner (ICML'25) | 逐层 K/V 位宽与准确率的联合搜索 | 标定分布是静态的，无未来查询 |
| Quantize What Counts (ACL'26 F) | 给 K 更多精度并给理论分析 | 单轮、单分布 |
| AATC (2026) | 注意力输出误差分解 + 按敏感性分配 | 目标是平均失真，不是轨迹尾部 |
| MixKVQ (ACL'26) | query-aware 的关键通道选择 | 用当前 query，不用未来 query 分布 |
| RateQuant (2026) | 失真曲线 + 率失真分配 | 同上 |
| TriAxialKV (2026) | 多轮/多模态的结构化精度分配 | 用结构标签，不是实测状态传播 |
| CalibQuant / HybridKV | 极低比特视觉 KV / 头分类分层预算 | 单次建缓存的质量，非长期复用稳定性 |

**差异点只有一句**：它们优化的是"某个分布上的期望失真"，我们要验证的是"**这个期望在轨迹上是否是一个坏目标**"。这句话必须由 P1 的实验支撑，不能由文献综述支撑。

## 3. 数学基础（修正后）

### 3.1 一阶读出误差

$$
\Delta y \approx \sum_i a_i\varepsilon_i \;+\; \sum_i a_i\big(\Delta z_i-\mathbb E_a[\Delta z]\big)(v_i-y),
\qquad \Delta z_i=\frac{q^\top\delta k_i}{\sqrt d}
$$

（推导与纠错见 `ERRATA_ARP_v1.0.md` E1。）

### 3.2 三项可直接检验的推论

| 推论 | 内容 | 检验实验 |
|---|---|---|
| **C1** | V 误差的方差为 $\sigma_V^2\sum_i a_i^2$：注意力越尖锐，V 误差越接近原样通过 | P1-C（按 $\sum a_i^2$ 分层注入） |
| **C2** | K 误差经 $(v_i-y)$ 加权，故值偏离输出越大的位置，K 精度越重要 | P1-B（只扰动 K，分层看 $\|v_i-y\|$） |
| **C3** | (II) 是协方差形式，保 top-k 幅值不足以保证次序 | P1-B 的"保幅值 vs 保次序"对照 |

**这三条如果实验不成立，方法的目标函数就不能用这个分解来构造。** 这是 P1 必须给出的第一个判决。

### 3.3 失真定义（不再用权重 MSE）

$$
D_{\text{out}}(c;q) \;=\; \big\|y_{\text{fp16}}(q)-y_{c}(q)\big\|_2^2 \big/ \big\|y_{\text{fp16}}(q)\big\|_2^2
$$

在真实 query 上测，不在随机高斯 query 上测。理由：ERRATA 附录已显示，attention MSE 与答案正确率的排序在 n=36 上不一致，必须用真实 query 分布。

## 4. 方法（条件式，不预设）

方法不是现在定的，而是由 P1 的判决选出来的。三种可能：

### 分支 1｜H-A 成立、H-B 不成立 → 轨迹鲁棒存储分配

$$
\min_{c}\ \ \mathbb E_{\mathcal T}\big[D(c)\big] + \lambda\,\mathrm{CVaR}_{\tau}\big(D(c)\big)
\quad \text{s.t.}\quad B_{\text{stored}}(c)\le B
$$

- $\mathcal T$：标定集上的会话轨迹分布（含多轮 query），不是单轮 query 集。
- $\mathrm{CVaR}_\tau$：轨迹失真的条件风险价值，$\tau=0.9$。
- 分配求解：整数背包贪心，$\sigma^2(b)$ 用实测曲线，不用高斯假设。
- **必须有的三个对照**：平均分配、平均敏感度分配（KVTuner/AATC 风格）、轨迹鲁棒分配。三者同字节。

### 分支 2｜H-B 成立 → 历史敏感读取

固定存储表示，只改读取策略 $\pi$，双预算：

$$
\min_{c,\pi}\ \mathcal L_{\text{traj}}(c,\pi)
\quad\text{s.t.}\quad B_{\text{stored}}(c)\le B,\ \ B_{\text{read}}(\pi,s)\le R_s
$$

- $s$ 分开定义：② 后续轮文本 prefill、③ 逐 token decode。① 首轮视觉 prefill 不参与（量化尚未发生）。
- $\pi$ **只能依赖当前已知信息**：当前 query、当前轮已生成 token、静态元数据。禁止使用未来 query 或未来 attention。
- 若"产生持久历史状态的计算"与"只影响当前输出的计算"对精度敏感性不同，这才是阶段分离的合法依据；否则不做。

### 分支 3｜两者都不成立 → 不做方法

转为测量论文（协议 A/B + 现有方法排名反转），或终止。**不允许**用调参把不成立的结果救成成立。

## 5. 评测协议（两套，不许混）

| | Protocol A：Same-History / Teacher-Forced | Protocol B：Free-Running |
|---|---|---|
| 输入 | 固定 token、固定位置、冻结历史 | 各方法自行生成并自喂 |
| 比什么 | 注意力输出、logit、新产生的 state | 答案质量、完整会话成本 |
| 用途 | **机制归因**（H-A/H-B 只能在这里判） | **应用质量**（主表） |
| 风险 | 低估生成分歧的实际影响 | 无法区分误差来源 |

规则：
1. 任何"因为压缩导致 X"的因果句，必须来自 A。
2. 任何"在实际使用中更好"的句子，必须来自 B。
3. 两套的样本必须同源（同 session 集合），但不要求同轨迹。

### 5.1 数据集分工

| 数据集 | 角色 | 说明 |
|---|---|---|
| GQA grouped（398×8） | 受控漂移 | 同图连续提问，可控、可复算 |
| DocVQA hash-grouped（181×≥3） | 受控漂移 + 文本密集 | V 敏感 |
| ConvBench（577 组） | 真多轮 | 开放式，评测器需单独审计 |
| MMDU | 真多轮（长） | 只作鲁棒性证据 |

**GQA/DocVQA 是"把同图独立问题组织成会话"，不等于自然多轮。** 论文里必须这么写，不能混称为 multi-turn dialogue。

## 7. P1：机制判决（决定做不做方法）

规模：InternVL3-8B，60–100 会话，Protocol A 为主。

| 编号 | 问题 | 设计 | 通过判据 | 产出 |
|---|---|---|---|---|
| **P1-A** | t=1 的敏感度排序能预测 t≥2 吗？ | 对每 (层,头,轴) 注入固定幅度噪声，测 $D_{\text{out}}$；逐轮做排序相关 | $\rho<0.5$ → H-A 有戏；$\rho>0.8$ → H-A 死 | `mechanism/sensitivity_drift.json` |
| **P1-B** | 误差主要来自 K 还是 V？ | 固定 token，分别只扰动 K / 只扰动 V / 同时；按 $\|v_i-y\|$ 与 $\sum a_i^2$ 分层 | 得到 (I)/(II) 的实测占比，验证 C1–C3 | `mechanism/kv_injection.json` |
| **P1-C** | V 误差是否 $\propto\sum a_i^2$？ | 按注意力集中度分箱，测 V 扰动后的归一化输出误差 | 单调关系成立 → C1 立；不成立 → 修正公式的实用价值下降 | `mechanism/attention_concentration.json` |
| **P1-D** | 历史状态有独立影响吗？ | 固定 token/位置，替换上一轮 KV 分支（合法分支，非任意张量） | 存在可测 $\Delta$logit 且跨会话稳定 | `mechanism/history_crossover.jsonl` |
| **P1-E** | 按 t=1 分配在 t≥2 的 regret 有厚尾吗？ | 用 t=1 排序做 3 档配置，在 t=2..T 上算 regret | $\mathrm{CVaR}_{0.9}$ 显著高于 oracle 下界 → H-A 可被方法化 | `mechanism/trajectory_regret.json` |

### 判决矩阵

| P1-A（漂移） | P1-D（历史介导） | 决策 |
|---|---|---|
| 成立 | 不成立 | 走分支 1（轨迹鲁棒分配），这是最省算力的一条 |
| 不成立 | 成立 | 走分支 2（历史敏感读取），但只剩系统层贡献，venue 降级 |
| 成立 | 成立 | 先做分支 1，再用分支 2 解释为何有效（两者互为机制） |
| 不成立 | 不成立 | **停止方法开发**，转测量论文或终止 |

**关键约束**：P1 全部用 Protocol A，且必须在同一执行器、同一模型版本下完成。跨执行器比较的结果一律不采纳（P173 已证明 backend 切换能改变 47–48% 的输出）。

## 8. P2：方法对比（只有 P1 判决通过才做）

### 8.1 基线分层（六层，缺一层都不完整）

| 层 | 方法 | 作用 | 实现要求 |
|---|---|---|---|
| L1 基础 | FP16、KIVI2、KIVI4 | 确定压缩损失与真实可改进空间 | 官方实现优先 |
| L2 固定非对称 | K4V2、K2V4、native4（独立 4bit） | 分离"K/V 位宽"本身的贡献 | 同 packed 格式 |
| L3 残差结构 | K-only residual、V-only residual、P202 asym | 证明非对称残差是否真有必要 | 复用 P202 代码 |
| L4 敏感性分配 | KVTuner-style、AATC-style、MixKVQ-style | 与已有算法思想正面对比 | **必须标注"机制移植"**，不得称为官方 |
| L5 视觉强基线 | CalibQuant、HybridKV | 检验真实 VLM 场景竞争力 | 先确认代码/权重可得 |
| L6 新方法消融 | 平均分配 / 轨迹鲁棒 / 历史感知 | 证明新增机制的独立贡献 | 严格等字节 |

**诚实性条款**：无法端到端复现的工作，在表里标 `† mechanism-port`，并在脚注说明移植了什么、省略了什么。禁止把自写近似写成 "X et al."。

### 8.2 等字节的严格定义

- 分母：该模型**视觉 token 的 FP16 K+V 字节**。
- 分子：`data + scale + zero + residual + alpha + padding`，逐项列出。
- 所有对比必须落在同一 $B$ 上（允许 ±0.5% 的 packing 误差，超出则重新分配）。
- **禁止**通过"同时换编码 + 换字节"来制造优势（ERRATA E3）。

### 8.3 战场选择（先证明有空间，再比方法）

对每个候选 (dataset, $B$, model) 组合，先测 $G=S_{\text{FP16}}-S_{\text{best base}}$：

- $G<5$pp → 只作"不劣"证据，不作主表；
- $G\ge5$pp → 可作主战场，报 GC。

预期需要往更紧的预算走（1–1.5 bit）、更难的子集（OCR、跨图关联）、更长的上下文（6.6k token）。

## 9. 指标与验收

### 9.1 质量

| 指标 | 定义 | 用途 |
|---|---|---|
| EM / ANLS | 官方脚本 | 主指标 |
| **GC** | $(S_{\text{method}}-S_{\text{base}})/(S_{\text{FP16}}-S_{\text{base}})$ | 主效应量（尺度无关） |
| Acc@turn | 第 t 轮准确率 | 漂移曲线 |
| worst-decile EM | 最差 10% 会话的均值 | 尾部鲁棒性 |
| CVaR$_{0.9}(D)$ | 轨迹失真的条件风险价值 | 机制层主指标 |

### 9.2 机制

| 指标 | 定义 |
|---|---|
| $D_{\text{out}}$ | 归一化注意力输出误差（§3.3） |
| $\Delta$logit / KL | 压缩前后 logit 分布差 |
| state divergence | 同位置隐状态的余弦/L2 差 |
| $\rho_{\text{turn}}$ | 跨轮敏感度排序相关 |

### 9.3 效率（只作约束，不作卖点）

| 指标 | 目标 |
|---|---|
| $B_{\text{stored}}$ | ≤ 最强基线 |
| $B_{\text{read}}(s)$ | 分 ②③ 两阶段单独报 |
| TTFT / TPOT | ≤ 110% 最强基线 |
| 完整会话 | ≤ 110% |
| 峰值显存 | ≤ +5% |

### 9.4 统计

1. 配对 + 图像级 cluster bootstrap（1000 次）。
2. MDE 由 pilot 的配对差向量模拟得出，**不硬编码**（ERRATA E5）。
3. Holm 校正；报效应量与 CI，不只报 p。
4. 每张主表附"该样本量能检测到的最小效应"。

## 11. 三种结局与投哪里

| 结局 | 证据形态 | 可写的主张 | venue |
|---|---|---|---|
| **仅编码更好**（P202 扩样本后仍成立，但 P1 全败） | 等字节下 GC 一般，无机制 | "一个有效的视觉 KV 编码组合" | 二区 / CCF-C；不宜冲 MM |
| **轨迹鲁棒分配胜强基线**（H-A 成立） | 等字节 + 尾部降低 + 强基线对比 | "平均失真目标不足以刻画多轮精度需求" | TMM / TOMM（CCF-B，一区/二区） |
| **历史误差传播被证实并被控制**（H-B 成立） | 协议 A 的因果证据 + 协议 B 的质量收益 | "多轮视觉 KV 的误差存在第二条传播通路" | ACM MM 等（CCF-A） |

**venue 说明**：

- **IEEE TMM**：CCF-B，中科院 2025 分区计算机大类 1 区 Top，IF 8.4–9.9。rolling 投稿，是最稳的完整长文目标。
- **ACM MM 2027**：已确认在香港举办，但**官方尚未公布截稿日期**（此前流传的 2027-04-08 属第三方推测）。**不把研究节奏绑定在该日期上**，等 CFP 正式发布再决定。
- ACM MM 对"多媒体/多模态本身"的贡献要求较高。若论文只是"把 LLM KV 量化搬到 InternVL"，领域独特性不足——这正是必须做 H-A/H-B 的原因。

## 12. 停止规则（写死，避免重演）

1. **P0 未全通过，不启动 P1。**
2. **P1 两个假设都不成立，不做方法**；不许通过调 $\lambda$、换层、换头把结果救回来。
3. 任一主表若依赖"base + 变体"的物化口径，该表作废。
4. 任一因果句若来自 Protocol B，改写或删除。
5. 任一基线若为机制移植，必须标注；不得与官方结果混排。
6. 单次运行的最佳值不得进入表格。
7. 不再新增 P 编号；实验编号固定为 P0-A…P2-x。
