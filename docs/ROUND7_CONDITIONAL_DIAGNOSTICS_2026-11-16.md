# Round7 条件交换诊断：策略有效性与反馈机制归因分开

本报告只读取已经完成的校准和 policy-select 结果，没有读取正在运行的新来源确认预测。当前证据支持“真实 packed 交换能找到改善训练目标的全局策略”；**不能把条件策略的表现归因于接受后反馈重估的独立贡献**。相同候选、相同分批上限下，初态静态加和与初态静态整对分数均能精确重建全部条件策略。

## 1. 证据范围与目标口径

审查对象为 `results/round7_v1/exchange_cal8_pairs8/`、`exchange_key_cal8/gt/`、`exchange_key_cal8/self/` 的 `summary.json`、`cases.jsonl`、`packed_scores.jsonl`、候选和最终 policy，以及 `policy_select_doc_analysis/`、`policy_select_text_analysis/` 的完整汇总和逐题分数。没有新增 GPU 任务，没有修改已冻结 policy 或旧输出。

每次校准都是 4 个 Doc 来源、4 个 Text 来源，共 14 问；Doc 每源 2 问，Text 每源 1/2/2/1 问。先按来源内问题均值、再按数据集内来源均值、最后 Doc/Text 等权。重复干预与同源多问不增加独立样本数。来源按既定哈希顺序选取，题目按既定题号顺序取前至多两问，没有按本轮 loss、margin 或 entropy 选题。

GT 是固定首参考加 EOS 的多 token teacher-forced 平均 NLL；Full 自目标使用同一冻结 Full 模型最多 4 个自生成 token。所有候选重放整个问题后缀和相同目标历史，每次重建干净 cache，调用真实 packed reader。该口径是缓存前缀校准诊断，不是自由生成准确率或端到端时间。

K2 使用原 Text 首个标注；K1 使用事先固定的 normalized-plurality 首参考。比如 `r7_text_train32_38548` 的 GT token 序列发生变化。**两条编码路线的 GT NLL 绝对水平不能直接比较**；下面只比较各自固定目标下的策略变化。

## 2. 连续目标确实改善，但 K1 收益集中

数值单位为 nats/token，按上述来源宏平均。

| 编码/策略 | GT NLL | Full 自目标 NLL |
|---|---:|---:|
| K2 incumbent | 0.925246 | 0.211108 |
| K2 全局静态加和/整对 | 0.904184 | 0.210656 |
| K2 条件分批 | 0.902487 | 0.200816 |
| K1 固定 43-stage incumbent | 0.453108 | 0.410440 |
| K1 全局静态加和/整对 | 0.250042 | 0.214660 |
| K1 条件分批 | 0.242635 | 0.210171 |

K2 条件策略的 GT 改善为 0.022759：6 个来源改善、2 个变差，最大正贡献来源占正收益的 23.0%，前两来源占净收益的 43.3%。把任一来源从已选定策略的评价中去掉，保持数据集等权后，剩余改善最低仍为 0.019124。其收益没有由单一来源决定。

K1 条件策略的 GT 改善为 0.210473：最大来源占正收益的 54.6%，两个 Text 来源合计占净收益的 89.3%。两者是图像哈希前缀 `5bed5994…`（题目 38548/38549）和 `a72aea3e…`（题目 37218）。最大来源的来源平均 NLL 改善为 0.918696，另一来源为 0.585304。去掉任一来源后最低改善为 0.120691；同时去掉这两个来源后改善降至 0.024476。因此，**K1 改善明显受少数来源集中影响，但移去单个来源不会使已选策略的改善变号**。

以上删源结果是在原训练数据已经选好策略后，对固定策略重新汇总；不是留源重训，也不是无偏泛化估计。不能把它写成“反馈学习在未见来源上稳定有效”。完整的逐来源贡献和删源口径见诊断 JSON。

## 3. 整对交互非零，却没有证明必须验证整对

同一个学生状态下，记 `P=(L0-Lremove)+(L0-Ladd)`，`A=L0-Ljoint`，交互量为 `A-P`。两单动作使用固定完整 ranking；移除后不补冷位，添加单动作允许多一级诊断，整对保持原 stage 数。交互比较的 anchor、目标和候选一致。

| run/评分状态 | `mean abs(A-P)` | `max abs(A-P)` | 加和/整对正负分歧 |
|---|---:|---:|---:|
| K2 初态 | 0.000685 | 0.002757 | 0/8 |
| K2 条件当前态 | 0.000742 | 0.001430 | 1/8 |
| K1 GT 初态 | 0.002905 | 0.010804 | 0/8 |
| K1 GT 条件当前态 | 0.003560 | 0.012703 | 0/8 |
| K1 self 初态 | 0.002823 | 0.010690 | 0/8 |
| K1 self 条件当前态 | 0.004092 | 0.013324 | 0/8 |

例如 K1 GT 初态 swap_03 的加和改善为 0.087479，整对实际改善为 0.098282，存在 0.010804 的正交互。K2 当前态 swap_02 则从加和预测 −0.000188 变为整对 +0.000543。但该候选没有赢得所在批次，最终决策未因此改变。全局静态加和与全局静态整对最终选择的集合在这些 run 中相同；不能据交互不为零就声称整对验证产生了额外策略收益。

## 4. 精确等价对照揭示本轮消融的混杂

现有“全局静态”从全部候选里取至多 4 对正分交换，同一批可以选多对；条件方法则按 4 批、每批最多接受 1 对。这同时改变了评分状态与选择约束。

保持冻结候选顺序、原 4 个分批、相同正改善接受规则，并且**始终只用初态分数**，重放结果如下：

| run | 条件方法实际接受 | 初态加和、每批至多一对 | 初态整对、每批至多一对 |
|---|---|---|---|
| K2 GT | 00, 03, 04 | 完全相同 | 完全相同 |
| K1 GT | 01, 03, 04, 07 | 完全相同 | 完全相同 |
| K1 self | 01, 03, 04, 07 | 完全相同 | 完全相同 |

CPU 审计逐项验证了完整 224 项 ranking、所有 `selected_stages` 顺序，以及除展示名称以外的全部部署参数相同；再按实际 book、factor、stage 池和视觉长度重算完整 owner，与已保存真实 packed 最终记录一致。原文件 SHA 在审计前后保持不变。

因此，当前反馈评分**改变了一些预测值，但不是生成这些最终 policy 的必要条件**。现有条件策略相对全局静态的 select 表现也不能分离“分批选择约束”与“接受后重估”的贡献。精确对照是等价 alias，可直接复用原条件策略的真实自由回答，不能复制成新的独立实验记录或增加样本数。

可复核命令：

```text
python code/a2/round7_exchange_equivalence_check.py
```

结果见 `audit/a2/round7_matched_static_batch_equivalence_v1.json`。该 CPU 检查不会读取新来源确认记录。

## 5. 逻辑预算相同，物理调用是跨方法共享的账

这三个正式校准 run 均为 8 对候选、4 批。每方法的控制器逻辑上限为 `2×4 + 3×8 + 1 = 33` 次 allocation 评价：每批 anchor 与结果验证、每对 remove/add/joint、最终策略验证。14 问同时评分 GT/self，逻辑上限为每方法 924 次 packed 后缀前向。

K2 的共享执行实际产生 49 个 allocation、1,372 次 packed 后缀前向；K1 GT 和 K1 self 各产生 50 个 allocation、1,400 次。相同输入复用了分数；这些是整个三策略 campaign 的物理调用数，不能说每个方法都独立付出了同样物理调用或同样时间。Full 原生预填充、自目标生成和原生参考控制没有计入上述 packed 计数，因而也不是端到端校准成本。

精确静态分批 alias 需要的初态干预更少：加和使用 16 个 singleton 加 1 个 baseline，即 17 个 allocation；整对使用 8 个 joint 加 1 个 baseline，即 9 个 allocation。当前 14 问、同时保留两个目标时分别为 476/252 次 packed 后缀前向；若仅评分选择目标则为 238/126 次。形成 policy 不需要先做每批学生状态重估；额外一次最终验证可选，现有实际条件策略结果可直接验证等价 alias。

K1 的 baseline/joint 是固定 43-stage，remove/add 分别为 42/44；完整 owner 随图像长度变化。本轮校准和 select 最大值为约 1.300252 bit/scalar，不能写作每图均不超过 1.3。K2 相应最大值约 1.799985。

## 6. Margin、entropy 与 teacher-forced argmax 的读法

下表 margin 和 entropy 按来源宏平均；正确题数为 14 问的描述性计数。

| 路线 | GT 首 token margin，初态→条件 | 首 token entropy，初态→条件 | 首 token 符合 GT | 全 teacher-forced argmax 序列符合 GT |
|---|---|---|---|---|
| K2 | 2.1572→2.3091 | 0.4962→0.4809 | 10→10 | 7→8 |
| K1 | 4.2637→4.6670 | 0.5662→0.5709 | 10→12 | 7→9 |

两路线均有 2 问改变首 token top1、3 问改变 teacher-forced argmax 序列。这里的后续 logits 以固定 GT/Full token 历史为输入，不是模型沿自己输出继续解码；“全序列符合”也不是自由回答准确率。K2 自目标首 token 一致数反而从 13 降至 12，尽管自目标平均 NLL 改善，说明 NLL、margin 和离散 argmax 不能互相代替。

K1 最大改善题 38548 很能说明首 token stress 指标的局限：初态首 token margin 已为 10.875、entropy 仅约 0.000303，第一词非常确定；真正的误差在后续 token，GT token NLL 为 `[0.000025, 2.486013, 5.101593]`，条件策略变为 `[0.000031, 1.980967, 0.094458]`。只按首 token 不确定性富集，会漏掉这类高贡献题。现有逐 token NLL/margin 足以观察这个现象，无须临时增加门槛。

K1 GT 与 self 的四份最终 policy 文件全部字节相同，但这不是两个独立复现。两者使用同一来源、候选、模型；14 问里 10 问首目标 token 相同，Text 6 问中 5 问完整目标序列相同，另 1 问的 self 只是 GT 的前 4 token。该结果只能说明这次有限候选上的目标消融没有改变最终选择。

## 7. 已完成 select：有方向信号，没有统计优势结论

| 方法 | Doc ANLS，38 问/16 源 | Text 准确率，22 问/16 源 |
|---|---:|---:|
| K2 incumbent | 93.7626 | 90.9091 |
| K2 全局静态 | 88.8503 | 90.4545 |
| K2 条件/精确静态分批 alias | 93.8002 | 95.0000 |
| K1 incumbent43 | 89.5974 | 86.3636 |
| K1 全局静态 | 89.5974 | 86.3636 |
| K1 条件/精确静态分批 alias | 92.2289 | 90.4545 |

K2 条件对 incumbent 的 Doc 增量只有 +0.0376pp，来自一题 ANLS +0.014286；Text +4.0909pp 来自一题评分 +0.9。K1 条件对 incumbent 的 Doc +2.6316pp 来自一题 +1，Text +4.0909pp 也仅来自一题 +0.9。K1 全局静态与 incumbent 的全部逐题分数相同。改善并未覆盖很多新来源。

按已有来源聚类分析，条件对 incumbent 的 95% 区间分别为：K2 Doc `[0, 0.1261]pp`、Text `[0, 14.2105]pp`；K1 Doc `[0, 8.3333]pp`、Text `[0, 14.2105]pp`。四个原始来源 sign-flip p 均为 1，报告全比较族 Holm 后也均为 1。bootstrap 下界落在零并不构成统计显著优势。

Doc select 与本次拟合来源分离，但源自历史 cal32；Text select 是本轮新增开发来源。两者已经用于查看和挑选本轮策略，现有分析明确标记 `new-fit-select-not-pristine`，不能升级为全新盲确认。训练目标的改善与这批稀疏自由回答变化应分别报告。

## 8. 独立解释与后续约束

目前可保留的是：低码率 KeyBank 与固定 stage 位置组合值得进入已冻结的新来源确认；真实 packed loss 干预比单看梯度排名更接近实际候选效果；分批选择得到的 policy 在已完成 select 上有可观察方向信号。

需要撤下的是：“条件反馈优于同等静态控制”“整对交互证明必须实际验证整对”“GT/self 两次成功是独立复现”“少于 1.3 bit 每图”“select 已证明泛化优势”。精确 alias 已经覆盖最关键的控制缺口，不需要为了补一张对照表重复运行同一个 policy。

当前冻结方法和新来源确认保持不动。确认结束后先报告预先冻结的策略效果、来源聚类区间、完整字节与同输出成本；若后续确需研究反馈重估的独立贡献，应让静态与条件使用完全相同的分批和接受上限，只让评分状态不同，并寻找真实改变最终选择的情形。对于 stress 观察，使用已经记录的全目标 token 轨迹，明确来源身份与富集规则；不得把训练诊断挑出的少数高收益来源当作总体确认。

数值及输入 SHA 汇总：`audit/a2/round7_conditional_diagnostics_summary_v1.json`。精确等价、字节重算、原文件保留与 alias 规则：`audit/a2/round7_matched_static_batch_equivalence_v1.json`。
