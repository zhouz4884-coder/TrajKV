# TrajKV：第一轮完整探索周期

用户于 2026-11-12 授权持续完成附件最后的两周研究计划。本文件记录本轮实际执行范围；旧 PLAN v2/v3 保留为历史，不能用其中单一效应或 τ 阈值阻止本轮算法探索。

## 研究问题与工作方式

研究多轮视觉 KV 的精度投入位置、投入时机及历史误差处理。执行器标定、数据接入、基线和算法原型并行；根据观察修改机制。阶段是研究任务顺序，不表示已消耗十四个自然日。

1. 恢复 InternVL3 执行器；同文本四臂状态干预及替换/重放空白对照；运行开发会话与基础基线。
2. 精化位置/时机、K/V、事实载体与非载体、当前与未来影响、五档残差剂量探索；同时建立离线 oracle。
3. 实现写入感知/未来收益表原型及 margin 触发版本；比较均匀、随机、周期、当前敏感度和相同成本策略。
4. 在隔离图像上运行自由生成；加入近期强量化方法的可执行参照；输出原始记录、配对统计与资源—质量曲线。

## 补充建议的技术解释

- 低精度 margin 是下一 token 翻转风险的候选信号，不保证相同 token 下状态无害。先试算、再触发、回滚重算、最后提交；新增 probe/replay 成本全部记录。当前 logits 决定下一 token，当前写入的 KV 属于刚消费的 token，必须明确位置。
- 同一 token 串在参考视觉条件下重编码若改善后续表现，支持数值历史状态路径；不能解释为仅文本错误。若未改善，还需区分文本问题与重算范围。
- H-K 作为探索假设：比较载体 K 与 V 精化的长期收益。K 的归一化影响不意味着 V 不传播；单 token 和多 token 事实 span 都测试。
- 桥接描述协议是人为控制的历史通道压力测试，与原生对话分开。短答案同样可能是重要载体。后续题目与顺序在观察模型结果前确定。
- 当前—未来散点寻找的是小当前改善、大未来改善及动作排序反转；坐标单位不同，不解释几何对角线。
- 预测期望未来收益可使用离线数据和在线特征；这不等于在线查看未来。每个特征标记 online/reference/future，后两者只用于诊断/oracle。
- 固定存储/事件级读取已有直接相关工作 ReadKV (arXiv:2610.11245)，作为机制参照，不预设此资源建模为原创。
