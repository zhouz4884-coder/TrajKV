# TrajKV：从项目开始至今的研究进展

本记录覆盖2026年11月12日启动TrajKV以来的主要路线、实验与判断。项目沿用VisContract_P14_2的历史代码和模型资产，目标是形成论文所需的机制洞察、可部署方法和可信证据。下面按研究阶段整理，开发、诊断、确认与准备工作分别标明；研究工作包不等于已经经过十四个自然日。

## 1. 最初的问题：低精度读取会不会影响后续对话

最初围绕“视觉读取误差经文本或数值历史继续影响后续回答”，并行探索事实载体K/V、写入margin、局部重算、当前/未来收益表、双读探针和周期精化。建立了完整InternVL3-8B-hf的GPU执行器、base+residual真实packed读取、实际调用资源账以及同token分支仪器。

主要结果不是触发器成功，而是找到了它的局限：

| 已完成工作 | 范围 | 结果 |
|---|---|---|
| CLEVR主评测 | 64图×10问×19配置，12160回答 | 新触发/收益表没有稳定胜过简单控制 |
| 独立阈值复测 | 32图×10问×12配置，3840回答 | 请求升级比例可标定，质量优势未建立 |
| 四预算扫描 | 上述32图中16图，2560回答 | cohort嵌套，不增加独立图像数 |
| Doc探索→确认 | 探索16图；确认64图294问×12配置 | 未来表探索+2.43pp，确认只+0.137pp，区间跨0 |
| 机制/外部 | 同token四臂、载体手术、GQA/ConvBench/描述桥接 | 数值状态路径存在，H-K与margin没有成为通用损害判据 |

这一阶段促使主力从“何时多读一次”转向“压缩表示到底丢了什么”。它没有证明后续状态影响不存在，也没有为原触发方法建立论文级优势。

详见[第一周期完整报告](RESEARCH_CYCLE_REPORT_2026-11-12.zh.md)、[机制](EXPLORATION_MECHANISMS_DEV_V1.md)、[Doc确认](DOCVQA_CONFIRM64_REPORT.zh.md)。

## 2. 极低比特：先分开电平、分组、范数与方向

随后比较min/max、sign、MAD、Lloyd、分组轴、元数据范围、K/V独立精度与范数×方向四臂。这里的重要修正是：1.25、1.31或1.09bit是若干编码的成本点，不是推导出的理论最优；Gaussian电平推导也不等于整个模型有一个普适SNR可用性门槛。

100图开发中的真实packed结果提供了强线索：

- K2/V1由原生min/max的65.53 ANLS，换成per-channel Lloyd V1后达到82.06，视觉价格同为约1.752bit/scalar。分组与重建规则必须分别控制。
- K1/V1同档格式经去中心RMS修复可大幅恢复质量，但未接近高质量参照。不能据此宣称一比特K已经解决。
- 在后续新64图确认，K/V一比特Lloyd为30.48，同码率RMS修复达到60.15。它是实际重建规则收益，不是额外读取或参考分支。

更干净的K范数/方向诊断将V固定为FP16，四臂全部材料化为FP16：量化范数+方向51.03，真实范数66.49，真实方向85.05，Full87.95。方向臂比范数臂高18.56pp，配对95%区间[13.86,23.74]pp。范数自身也有15.46pp收益，不能说“长度无关”；四臂不能转成因果能量百分比。

这些诊断指导了旋转、向量码与元数据校准，诊断oracle不进入低比特部署价格表。

## 3. 校准与问题状态：先得到信号，再检验边界

第一组只优化量化因子，基础模型冻结、无标准答案，参数折叠原有F16元数据。区分两种合法工作负载：图像+问题原生prefill后压缩，以及压缩好的图像前缀接收新问题。当前部署研究关注后者，首问题状态完整通过压缩前缀重算，不共享FP16首logit。

新64图、286问、33配置、2112次自由会话、9438条答案完成确认。初始“压缩状态条件校准”比原生历史条件高6.73pp；该差别还在128图外测中出现。但用新的32校准源文档、identity初始化和多token目标后，差别缩小，随后warm联合版本也可更好。因此当前不主张cold校准总能胜过warm。

同一阶段得到约1.705bit的方向码K/Lloyd V1候选，确认ANLS82.56；原主校准候选81.13。两者都没有达到强参考0.5pp目标。KVarN数值质量端口同时持有FP16重构和packed记录，约18.39bit，作为质量参照保留，不画成2bit部署胜利。

详见[该周期发现与边界](RESEARCH_DISCOVERIES_2026-11-14.zh.md)。

## 4. 更大新源文档：表示收益复制，prefill额外优势未复制

固定公共DocVQA验证导出版本，并排除旧图池涉及的212份源文档，另分cal32/dev64/confirm256。每份源文档只选一页，按ID固定至多6问，不按压缩掉分挑样本。

新确认共256份源文档、999问、23配置、5888次自由会话、22977条计分答案：

| 配置 | ANLS | 视觉bit/scalar |
|---|---:|---:|
| Full | 92.21 | 16.002 |
| Native4，固定强参考 | 92.51 | 4.252 |
| Base2 | 90.44 | 2.252 |
| 方向码主候选 | 89.72 | 1.705 |
| K2/Lloyd V1 | 86.37 | 1.752 |

方向码比Lloyd高3.35pp，95%区间[1.43,5.50]pp，Holm p=0.0058；这一相对收益在新源文档上成立。距Native4仍低2.79pp，存储强质量目标未达。额外的新Text128分层外测没有复制方向码对Lloyd的普遍优势。

同存储的读取策略中，冻结主方案额外逻辑读量少60.62%、总逻辑KV读量少23.21%，ANLS相对all低0.31pp；点目标通过，95%区间[−0.82,0.17]pp尚不建立0.5pp非劣。开发集看到的prefill额外保护优势没有复制。

6图、16方法、3测量重复的288次测量和96次预热全部核验：固定每问题同8个输出ID，读取主方案会话中位3.082s、all3.036s；减少逻辑字节尚未成为会话加速。cached选择比fresh选择成本低，选择开销值得摊销。

详见[开发](ROUND3_DEVELOPMENT_2026-11-14.zh.md)、[完整确认与计时](ROUND3_CONFIRMATION_2026-11-14.zh.md)。

## 5. 码本与V修正：更便宜的部分开始显现

实际packed前向与直通梯度下，用完整冻结8B模型校准逐层/KV-head的K重建表，以及可选V增益/中心。4个400步拟合后，完成1152次开发自由会话（960唯一配置会话+192重复控制）、704条连续指标和3136条几何仪器记录。

只学K表在开发与独立输入KL上没有明显改善；联合V修正更有效。同一份联合拟合做K-only/V-only四臂，避免把联合效果全算给K。V-only与global的K完全相同，后续层query仍改变，说明V可通过隐藏状态影响后续路由。它不证明跨轮误差必然累积。

随后在另一128份新源文档、501问、18配置上完成2304次自由会话、9018条答案：

| 方法 | ANLS | 视觉bit/scalar，含规定encoder常量 |
|---|---:|---:|
| Native4 | 91.68 | 4.252 |
| Base2 | 87.74 | 2.252 |
| 冻结warm联合主候选 | 87.47 | 1.731 |
| warm联合拟合的V-only应用 | **87.73** | **1.695** |
| 未校准global方向码 | 86.01 | 1.695 |

V-only比global高1.72pp，区间[0.54,3.13]pp，Holm p=0.0382。它相对Base2的视觉价格少约24.75%，点分几乎一致；这尚不是等质量证明。学习K表没有在V-only之外建立独立额外收益。固定主候选距Native4低4.21pp，强质量目标仍未达到。

排除旧图池全部641图像ID后的新Text256（数字/文字主答案各128）也全部完成：V-only81.09%，Base280.63%，Full81.21%，Native481.99%。总体点结果有前景，但主要比较的区间较宽；这是分层子集，不是官方整体分布分数。

详见[码本开发与仪器](ROUND4_CODEBOOK_DEVELOPMENT_2026-11-14.zh.md)及`results/book_confirm_doc128_analysis`、`results/book_confirm_text256_analysis`。

## 6. 当前收尾范围

更小功能参数化的12个拟合、19配置开发以及另128份新源文档485问的8配置确认均已完成。约1.695bit主方案ANLS87.87，Base288.76；约1.579bit整图方案86.60。整图方案校准相对同价未校准控制高3.57pp，95%区间[1.51,5.71]pp，主要Holm p=0.00372。

复用Text256的512回答也完成：两方案分别81.45%、81.02%，Base280.63%。它们是转移复用；新源文档才承担本轮独立确认。固定输出36测量/12预热中，主方案2.641s、Base22.426s，当前有存储—质量交易，尚无加速。完整结论和下一步方案见[本轮收尾报告](RESEARCH_PROGRESS_AND_NEXT_PLAN_2026-11-14.zh.md)。

完整TextVQA5000问的数据和8方法配置已准备、哈希核验；根据探索阶段的时间价值判断，4万次回答在GPU开始前暂缓，没有当成已运行结果。候选稳定后再做大基准。

目前实证最强的推进方向是：先修可用的K几何，再看V与后续状态的条件化失真，以实际价格选择修复。已有的旋转、向量码和输出分布校准明确归属既有研究，组合价值由受控比较和完整模型结果体现。

## 7. 证据与运行边界

所有主模型实验在双RTX3090 24GB，完整InternVL3-8B-hf、28层/4KV heads/D128、统一FP16，无CPU模型替代或付费模型API。CPU负责调度、统计与绘图；学校V100未使用。

部署候选读取实际packed视觉KV，文本保留FP16。bit/scalar是规定的视觉缓存账户，包含相应payload/元数据/位置/常量，并在资格中计入encoder因子，不等于整个模型显存或峰值压缩率。逻辑读取量不是物理HBM交易；当前没有可靠HBM计数器结果。

开发、确认、oracle、teacher-forced分布代理、固定输出计时和取消任务在材料中分别保留。旧理论草案和计划用于理解研究过程，当前结论以上述完整评测及更新记录为准。
