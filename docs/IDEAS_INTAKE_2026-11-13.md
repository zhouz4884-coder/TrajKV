# 追加建议的取舍与实际执行

用户追加的两份建议作为研究材料处理。文件内“今天必须”“判死”“确定性胜局”等表述不自动成为执行约束。

## 吸收的内容

1. 扩大 1-bit/K-only/V-only 到新图像；实际等字节扫 K/V 分配，残差不分配时真正删除所有者。
2. 检验较低 K 精度覆盖更多层和较高 K 精度覆盖少数层的区别；本轮增加真实独立 K2/V1 与 K1/V2 base、单 bit K residual，而不是重命名原 K-r2。
3. 比较 128-token 与 256-token 页，选择采用 metadata 路径，避免完整 K_base 预扫描。
4. C 区分可从图像再得的事实和对话私有绑定，在同 user role 内反转顺序。真实 compact、保留原位置；部署删除和干净重编码分别执行。
5. 除单个算子局部误差校准，再试完整后续 logits 的层移除敏感度。两种校准均只用 dev8，不能事后挑新确认题。
6. 补充 KVarN2 keys + one-bit values 的小规模组合数值原型；先测质量，若没有 packed reader，则 packed 编码率只作虚线质量参照，不宣称运行时内存收益。

## 修正的推理

- 27 是旧64确认中 Full exact 对而 Base2 exact 错的子集，不是 Base2 全部错误；20/27=74.1%，不能从此推出总可恢复空间已经吃掉94%。
- 旧 CLEVR 的 8图80题是答案准确率，不应自动改叫 DocVQA ANLS。本轮新增 Doc dev8 为37题。
- 1-bit base +2-bit K residual 是 K 名义3bit，不是 K2；包括 group 元数据后 K-only 在该编码中约2.375 effective bits/KV scalar。无 residual 的 Base1 自身约1.25 effective bits/scalar。
- 原层配比网格固定 12/24/36 个成本槽：一层 K-r2=两个 V-sign 槽，实际有效位宽约1.49/1.73/1.97。0.5-bit base 并无现成内核，未冒充已经实现。
- CalibQuant 原论文有多位宽表，patch 中 calibquant 和 qjl 是不同 forward。新增 post-scale 数值对照及少量开发超参调整，以检查模型迁移和 FP16 运算次序影响。
- 对 `score=q·k/sqrt(d)`，CS 界是 `||q||||e||/sqrt(d)`；在各向同性的额外假设下，典型波动才可能约为 `||q||||e||/d`。把 gamma=1.5/2/3 乘在原 CS 界上会更松，不是自动收紧。开发分位数也不能无条件称为序列级概率证书。
- 页均值、top-k尖峰与 query投影是诊断量，不是干预收益的充要条件。未接受 raw MSE 平坦就停止页选择的门。
- 当前 P202/A2计算块 BN=32，量化组=128；64 子页会共享 K 元数据，需另算读取成本。当前实现/实验是128、256页，未将它写成已完成的64页方法。
- Thumbnail 位置需核对实际处理器，不能假定前256 token；旧 InternVL 示例把 thumbnail 追加在最后。先行缩略图也不能保证 running maximum 已代表所有细节页。本轮不为这一未经验证假设重排缓存。
- 保存字节和每次读取字节是两个资源轴，不能把释放1字节历史自动换算成1字节带宽。额外保真度若需未保存的源，必须重编码并收费。C 中 Native4 若超过 keep-Base2 拥有字节就明确标过预算。
- 驱逐既有 post-RoPE KV 时保持原位置；不对留下的旋转后向量直接重新编号。

## 当前经验信号

第一轮页核144个GPU检查通过；工作点扫描96会话完成。新 Doc dev8 的 K-only 81.38 ANLS、Base1/V-only均0，Full84.75。多个低总存储层配比仍崩溃，表明“只给少数层更高 K 精度”不能直接替代普遍的 K 保真度。以上用于研发，不作新确认的结论。
