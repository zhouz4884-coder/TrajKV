# Round8：KL 拟合改善为何没有变成任务收益

研究起始于 2026-11-18，本文在 2026-11-19 完成。**本轮研究执行已完成，指标目标失败：没有建立相对 R7 的稳健质量—成本前沿提升。** GitHub 同步单独核验，发布完成状态以发布回执为准。

最后固定的 336 参数校准将训练 KL 降低 75.03%，在训练来源外的八个已暴露选择来源上也将 Full-self KL 降低 33.22%；但该诊断的 teacher-winner flip 汇总率未降低，三个独立新来源池的官方任务均值均略低于 R7，受控计时的整轮时间反而增加约 3.4%。本轮的主要发现是：更接近 teacher 的分布，并不必然改善离散回答；当前参数族还具有不能直接改变视觉 token 排序的条件性限制。

本轮在两张 RTX 3090 24GB 上运行 InternVL3-8B（FP16）的完整图像—问题—自由生成评测；模型、数据、结果及编译/临时缓存均位于远端 8TB 数据盘。本文任务结果只覆盖该主模型与所列数据和协议；CPU 几何分析及评分复核不计为模型端到端回答。

## 冻结方法和实际价格

最后候选沿用原有 packed K/V 编码、读出器和 f0，保留 full224 排序，执行前 42 个残差阶段，即 23 K、19 V。训练表形状为 FP32[3,28,4]，共 336 个参数，仅调整已有 g/S/m/alpha 字段；整数 J、V code、残差符号、均值与布局不重编码。部署保留一份 1,344 字节参数表，原参数、排序和策略继续计费，编码常数合计 3,141 字节。全部实际 Nv 下，完整 R42+表 owner 均不超过旧 R43。

训练使用 32 个校准来源、70 个问题和固定 200 步，目标为来源平衡 Full-teacher KL；前向为真实 packed 路径，反向为 dense STE。初始 KL 为 0.09217983596，最终为 0.02301817567。唯一最终表在新确认答案值解码前冻结；随后完成的开发评分和确认结果均不再改变它。

[方法冻结](../configs/a2/round8_v1/method_freeze_v1.json)绑定 40 份数值、输入及协议文件，SHA256 为 `af1c0c06090522ca92efa57b0d0d85b1ae4445606510cc0bc3e1f1a11f1ff4be`。最终表 SHA256 为 `f68dfe87199ff0215ee4aed85a203744577a76e70c97b03ba7079aaa04c8b090`，训练完成 marker SHA256 为 `9646c6c396deeb365d48fbdbb4eaef4e397d82d1716be63a7b04c4e436fcb7a5`。

## 开发结果没有支持稳定迁移

早期原生字典曾在 cap16 拟合、cap8 评价，32 个选择来源中有 23 个 Nv 不匹配；该结果保留为跨密度转移证据。修复后的匹配 cap8 链完成八个拟合端点、64 个校准来源和 660 次方法答案输出，Nv 不匹配为 0/32。小选择集上的 K 联合拟合、V 字典及 Final-Ray 的 Doc 峰值未在自然 64 来源上稳定保持；Mean 在自然开发上与 R7 持平，Gaussian8 的选择集 Text 峰值也未迁移。

## KL 改善与决策收益之间的落差

continuous8 使用训练来源外、但已暴露的八个选择来源，每源一个独立首问，至多八个 target tokens。所有候选在同一完整 Full-teacher 历史下评价；另设独立 canonical-GT 历史分支，不混合两个目标。实际执行 88 次 outer sessions、654 次模型 forwards。

| Full-self 指标 | R7 | identity R42 | learned R42 | 预算 K2/V1 |
|---|---:|---:|---:|---:|
| KL teacher→student | 0.450647 | 0.461241 | 0.300962 | 0.122381 |
| target NLL delta | 0.540195 | 0.543472 | 0.352756 | 0.165143 |
| teacher-winner flip rate | 0.125000 | 0.125000 | 0.125000 | 0.083333 |
| 固定 teacher top2 delta RMS | 2.738617 | 2.816986 | 2.524092 | 1.950803 |

learned 相对 R7 的 KL 下降 33.22%，但 teacher-winner flip 汇总率仍为 0.125。相同汇总率不代表逐位置翻转集合相同。固定 top2 delta RMS 减小，但有符号 top2 delta 由 −1.235807 变为 −1.316260，并未显示 teacher 决策间隔被一致恢复。在独立 GT 历史分支，KL 从 0.217579 降为 0.146870，NLL delta 从 −0.435037 变为 −0.504331，flip 汇总率仍同为 0.088542。

因此，不能只依据训练集与任务集表现不同，就将本轮失败简单归为过拟合：训练来源外的分布拟合也改善了。更窄、与现有证据一致的解释是，KL 目标和当前参数族改善了部分概率分布误差，却没有带来相应的离散决策收益。这是八个已暴露来源上的描述性诊断，不是新确认准确率，也不是对所有来源的因果证明。[诊断原始汇总](../results/round8_v1/final_continuous8_v1/summary.json)保留两个目标分支和工作量。

当前 K 参数族还有一个可直接推导的限制。对固定 query、同一 KV head 和相同可见视觉 token/mask，写重建 key 为 `k_i = μ + d_i`。本轮用一个正尺度 `s` 共同缩放 direction gain 和全部 K residual alpha，均值 μ 固定。在理想实数运算下：

`ℓ'_i = s ℓ_i + (1−s) qᵀμ / √d,  s > 0`。

后一项对该 head 的所有视觉 token 相同，因此视觉 token 内部的 logit 排序保持。它仍会改变视觉内部 softmax 温度，并可能改变视觉与文本的注意力总权重；V 变换也能改变读出。实际 FP16 字段分别舍入和累加，近 tie 的排序可能改变；后层 query 随状态变化，不能把该条件结论外推为全模型排序或输出不变。这个结构限制为后续方向提供依据，但它是否主导本轮质量结果，仍需分离 K/V 作用的实验验证。

两个旧训练问题、identity/learned 共四组首 target logits 路径检查均 top1 一致，最大相对 L2 为 `6.27534e−5`，max-abs 为 0.0078125–0.015625，均非逐字节相同。批量 teacher suffix 与问题独立 replay 的 FP16 形状差异可以产生此量级误差；这四组检查未发现明显的训练—部署首 target 错位，不构成全部部署路径无误的证明。[原始诊断](../results/round8_v1/postcal_trajectory_diag_instrument_v2/diagnostic.json)未使用新确认 GT，也未改变冻结方法。

## 受控成本未带来加速

quiet6 使用三个旧来源、六方法、每方法每来源一次 warmup 和三次测量，另有三次 Full canonical session，共 75 sessions，其中 54 次为测量。所有试验的八个强制 token IDs 与逻辑位置一致，quiet 边界均通过。时间包含输入准备、原生视觉前缀提取、编码、完整问题 replay 和八 token 解码，不含模型加载。

| 方法 | 完整视觉 bit 中位数 | 编码 ms 中位数 | 整轮 wall ms 中位数 |
|---|---:|---:|---:|
| Full | 16.002232 | 24.37 | 1282.62 |
| native4 | 4.252232 | 59.72 | 1351.68 |
| 对称 base2 | 2.252232 | 58.31 | 1331.82 |
| R7 | 1.294664 | 144.10 | 1476.47 |
| 预算 K2/V1 | 1.799985 | 161.65 | 1500.01 |
| learned R42 | 1.289851 | 207.93 | 1527.04 |

按原始中位数计算，learned 相对 R7 整轮 wall 增加 3.4248%，编码时间增加 44.30%。R7 和 learned 的 wall 四分位区间分别为 [1395.16, 1490.25] ms 与 [1453.89, 1571.68] ms。该结果属于三来源、固定八 token 的原型比较；它没有建立加速，也不外推为优化 serving 的吞吐、SLO 或全部长度行为。视觉 owner 计费不等于整体 GPU 显存。[计时原始表](../results/round8_v1/final_quiet6_v1/summary.json)和[独立重算](../audit/a2/round8_final_measurement_independent_v1.json)保留全部中位数、四分位数、真实 owner 与输出/quiet 控制。

## 本轮边界与下一步

本轮共保留 5,714 条有效模型答案、5,708 条 session-by-variant records，覆盖 416 个原始来源和 447 个问题身份。42 个 canonical producers 支撑 40 个分析视图，合并视图和旧基线复用不重复计数。训练、连续诊断、计时及 CPU fixtures 不计入任务质量答案。

失败 Mean v1 的 120 条原始 records 已保留，因无最终 `complete_mean.json` 而拒绝进入质量统计。训练 v1 的 step51 有限零 query 梯度被过严检查拒绝；v2 仅在新 source/run 中允许有限零梯度，继续拒绝缺失及非有限梯度，完成固定 200 步并记录六个有限零步骤。失败原件、参数和来源清单均未覆盖。

最终运行时采集覆盖 65 个 jobs、433 个源码对象和 65 份最终日志，来源缺口为零，46 份本地 manifests 的源码哈希均被覆盖。四个早期 generic Mean jobs 的 launcher snapshot 是源码可用性清单，实际 Popen entry 指向当时 SR 工作树；采集保留这个区别，没有将其改称为 snapshot 执行。最终 index SHA256 为 `674952a1659d631553991440dc0d621a4ae53c62fa95a044035d0ed61e42ca5a`。

下一阶段可优先短跑**匹配完整 KV 字节预算的密度交换**：求 `max A(N,Q), subject to C(N,Q) ≤ B`，比较 K1 可承担的较高视觉 token 密度，与强 K2/V1、对称 2bit 各自能承担的离散 crop grid。N 依据真实 tile 和 thumbnail 计数，不用 max_patches×256 近似；同一来源按图像尺寸和预算预定 grid，不按掉分挑样本，额外 vision/prefill 延迟全部计费。Doc 当前 Full(cap8) 已达到 99.44% ANLS，固定 N 再压低编码误差的空间有限，但 Full(cap8) 不是更高 N 的质量上限。

另一个候选是 64 参数、读出导向的 K 码本方向改动，使改变直接作用于 key 方向而非仅有正尺度。密度交换与方向码本均为未验证建议，尚无本轮实验支持；它们不是首次性声明，也不改变本轮冻结结果。
