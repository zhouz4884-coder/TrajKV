# 第一轮开发机制观察

本记录来自已完成的真实开发运行：四臂与动作实验 8 个图像会话；载体手术 4 个图像会话；KVarN 机制移植质量比较 8 个图像会话。来源哈希、逐项配对、图像聚类 bootstrap 和局部反例完整保存在 `results/analysis_mechanisms_dev_v1/` 与 `results/analysis_kvarn_dev8_v1/`。没有使用这些结果作独立测试集结论。

## 1. 同文本历史状态的影响已经能够被仪器分开观察

四臂实验包含 40 个 T2–T6 观测点，token、位置与分块一致。KL 方向为 `KL(完整参考轨迹 || 当前分支)`，统计量先逐轮求均值，再按原图像聚类重采样。

| 历史 / 当前视觉读取 | 平均 KL | 图像聚类 95% CI |
|---|---:|---:|
| Ref / Ref | 0 | [0, 0] |
| Ref / Base | 0.0300743 | [0.0139415, 0.0471662] |
| Base / Ref | 0.00228815 | [0.000722616, 0.00440841] |
| Base / Base | 0.0362112 | [0.0197064, 0.0530738] |

N1 完整参考重编码重复、N2 原始 base 自由生成与同 token 重放的最大 logit 差均为 0。历史路径的数值影响可测，均值小于直接读取影响。Base/Ref 的 argmax 变化总数为 0；Ref/Base、Base/Base 各有 3 个 token 的 argmax 变化。这些指标描述固定文本条件下的状态与分布影响。

在 Base 当前读取条件下替换参考历史，平均减少 KL 0.00613685，95% CI [0.00156467, 0.0113424]；40 个局部观测中有 12 个反向。当前读取换 Ref 也有 3 个局部反向。交互项平均 0.00384870，CI [-0.000673168, 0.00942736]。因此不应假设两条路径在每一轮都同向或简单相加。

## 2. 精化动作的当前与未来排序有差异

12 种层组×时段动作、每会话 2 个写入轮次，共 192 个写入干预。V1 的指标仍是固定 base 生成 token 的 log-probability 变化：它只能用于发现行为差异，不能充当答案正确率或参考保真收益。

12 种动作的全局当前/未来排序相关为 -0.1851。192 个干预中，当前目标 logp 为正、未来为负的有 21 个；当前为负、未来为正的有 16 个。完整排序与每个反向案例见分析 CSV 和 summary。V2 将主收益改为对同 token 完整参考轨迹的 KL 保真改善，以避免奖励 base 本身的错误文本。

## 3. 载体位置存在较强非均匀性，K/V 都值得继续探索

4 个图像会话提供 10 个词/位置候选案例；位置类型 3 档、K/V 两轴、剂量 5 档，共 300 个干预、600 个未来轮响应。实际选中 1 或 2 个 token 位置、相同 28 层，K/V 逻辑写入值字节为 28,672 或 57,344。所有 token schedule、位置哈希、匹配位置数、层集合及写入字节审计通过，控制位置与载体位置没有重叠。α=0 和数值空白的最大 logit 差均为 0。

α=1、未来两轮合并的平均输出位移 KL：

| 位置类型 | K | V |
|---|---:|---:|
| 载体候选 | 0.000300625 | 0.000751188 |
| Prompt 对照 | 0.0000130548 | 0.0000194953 |
| 随机位置对照 | 0.00000569341 | 0.00000565016 |

这里的 KL 是相对于原 base 轨迹的**位移**，较大并不自动意味着修复更好。600 个响应的 argmax 变化总数为 0。

保留以下重要局部信息：

- α=1 的 20 个载体 K/V 配对中，V>K 与 K>V 各 10 个；没有一致的单轴优势。均值 V 更大不能推出普遍 V 主导，数据同样不支持“K 必然复利、V 不传播”。
- α=1 的 80 个载体—对照配对中，10 个 Prompt 对照的位移超过载体。
- 120 条单案例剂量曲线中 63 条非单调，其中载体曲线为 23/40。聚合均值平滑上升不能抹去这些个体反例。
- 随机对照在 10 个 α=1 案例中有 8 个的状态干预 L2 为 0，K/V 均如此。资源匹配没有实现扰动幅度匹配。Prompt 对照全部有非零干预，因此比随机对照更有定位意义。
- α=1 平均干预 L2：载体 K/V 为 15.52/19.59，Prompt 为 11.70/18.09，随机为 2.57/3.56。后续可继续检验“状态误差集中”和“单位扰动敏感性”分别贡献多少。

## 4. KVarN 机制移植质量结果与运行时资源分开

同 8 张开发图像、80 道 QA 的规范化 exact：

| 方法 | 正确数 / 80 | 准确率 | 实际视觉张量 owner / FP16 视觉 owner |
|---|---:|---:|---:|
| Full | 41 | 51.25% | 1.0000 |
| Base2 | 44 | 55.00% | 0.140625 |
| Native4 | 41 | 51.25% | 0.265625 |
| KVarN2 机制移植 | 44 | 55.00% | 1.1484375 |
| KVarN4 机制移植 | 41 | 51.25% | 1.2734375 |

移植路径同时保留物化 FP16 视觉张量与编码参考，因此其编码比例不代表运行时驻留节省。分析脚本将其标为 `cost_comparison_allowed=False`，从 packed 执行效率图中移出，保留独立质量图与资源表。Base2 与 KVarN2 总分相同，但有 10 个回答文本不同、4 道题的正确性翻转，不能称作逐题等价。

## 5. 对下一轮原型的直接启发

继续主攻位置与精化时机的联合非均匀性，K/V 均保留为可选动作。用 V2 参考保真收益重排相同动作，再检查这种排序是否能够转成自由生成答案收益。载体结果提供了定位线索，同时提示使用非零幅度对照、保留个体剂量响应；不必将探索押在“K 一定优于 V”的解释上。
