## K2 的 exact 损失主要是字符串格式

3240 t1 的公司名称由 `R.J Reynolds Tobacco company` 变为 `R.J. Reynolds Tobacco Company`。前者是官方参考别名之一，后者新增了句点/调整格式后未精确匹配参考，ANLS 1→0.966667、exact 1→0；不能仅凭这个 exact 损失宣称公司事实变错。

两项部分改善则是 3102 t1 姓名从 `P.F. Khouse, Jr.` 变为 `P.F. Knouse, Jr.`，ANLS 0.882353→0.941176；3667 t1 批发商名称去掉一段错误字符，ANLS 0.852941→0.882353。它们都还没有匹配任何完整参考。因此 K2 的微小 ANLS 净增量也不等价于增加完全正确的答案数。

## 指标解释边界

官方 DocVQA ANLS 是字符相似度，不是数值等价或事实判断。`6000` 与 `6,000` 在数量解释下相同，但官方 ANLS 是 0.8；`4873` 与 `4373` 的数值不同，ANLS 仍为 0.75。exact 也受标点、内部空格和参考别名覆盖影响。因此主表同时给 ANLS 与 exact，并结合保存的实际输出解释，既不把 ANLS 当成事实全对，也不把每个 exact 损失都当成事实变坏。

以上变化来自同一批已完成自由回答，可能还受会话前序自生成答案影响；逐问表不提供逐问独立的因果干预。官方评分、冻结结果和总体比较范围均保持不变。
