# 精度条件与状态形成：可测试的数学表述

## 对象与两个合法工作负载

令 `P` 为原生图像因果前缀 KV，`Qθ(P)` 为以共享编码参数 θ 压缩的前缀。问题 token 串记为 q；将最后一个输入 token 单独留下，之前的问题状态记为 `H(P,q)` 或 `H(Qθ(P),q)`。函数 `F(P,H,q_last)` 消费最后 token 并产生首答案 logits。

这样可以精确区分：

1. 原生 image+question 联合 prefill 后再压缩：问题历史是 `H(P,q)`，之后重读最后 token；
2. 已压缩图像前缀接收新问题：问题历史是 `H(Qθ(P),q)`。

两个工作负载都合法。它们使用相同文本，并不具有相同问题 KV。因果性保证图像之前/内部的原生前缀不依赖后来问题；它不保证后来问题状态不依赖读到的图像精度。

## 一个精确恒等式，不作损失份额解释

在固定问题 token 下，加减中间项即可得到 logits 的恒等分解：

```
F(Qθ(P), H(Qθ(P),q), q_last) − F(P,H(P,q),q_last)
= [F(Qθ(P),H(P,q),q_last) − F(P,H(P,q),q_last)]
 +[F(Qθ(P),H(Qθ(P),q),q_last) − F(Qθ(P),H(P,q),q_last)].
```

第一项在固定原生问题历史下测读取影响；第二项测问题历史形成条件改变后的差别。它们是向量差的加法，不代表 ANLS、KL 或准确率的可加归因。两项可能抵消，不能将范数比或分数差叫作因果百分比。

目前100开发图上的三协议实验对应这一问题；新64/外部128的同参数量校准比较则验证了对齐形成条件的实际价值。它们没有证明“所有多轮误差必然累积”。

## 校准目标为何不同

以 `p*` 表示 FP16 教师，令 `D` 为词表分布 KL。保留原生问题历史时的校准针对

`L_native(θ) = E D(p*, pθ(. | Qθ(P), H(P,q)))`。

压缩前缀接收完整问题的校准针对

`L_state(θ) = E D(p*, pθ(. | Qθ(P), H(Qθ(P),q)))`。

对后者求导，除了编码参数对当前读取的影响，还有通过**较早问题 token 状态**返回的链式项。前者把这些历史状态固定了，缺少这部分依赖；它仍包含最后 token 内部经压缩视觉读取的影响，不能说完全没有状态梯度。

当前实际实现固定原始码字，仅优化编码元数据的共享 gain/offset；FP16 元数据舍入采用自动微分中的直通近似。模型权重冻结。以上目标解释依赖关系，不保证局部优化找到全局最优，也不声称某个 θ 是理论最优码率。

## 已观察到的证据

冻结224参数的状态匹配版，在新Doc64比原生历史版高6.73pp ANLS，在Text128高7.42pp soft accuracy；配对95%区间分别[3.33,10.46]和[2.73,12.58]pp。对强Lloyd对照的增益区间仍跨0。因此目前最清楚的证据是**匹配状态条件的重要性**，完整质量目标尚未达成。

## 正在验证：问题状态 × 答案位置

新32源文档的83个独立问题输入上，做首token/最多8个答案token × 原生历史/压缩状态的2×2；额外center参数另设两臂。所有多token目标的上下文是FP16教师自生答案，标准答案没有进入训练。

这一扩展覆盖更多答案位置，但仍属于教师上下文校准。若学生在自由生成中先写出了不同 token，后续会进入另一条轨迹。**覆盖多个位置不等于已经解决自由生成的上下文偏移。** 后续若训练KL降低而任务质量不升，应直接测这条差别。

一个后续候选是按学生当前生成的前缀收集配对教师/学生 logits：

`E_{y<~student} KL(pFull(.|P,q,y<) || pθ(.|Qθ(P),q,y<))`。

它需要额外离线教师前向，在线不需要教师；学生采样 token 的离散路径可暂不求导。是否值得，要由当前六臂自由生成结果决定，不把训练KL下降作为任务成功。

## 对读取策略的同一启发

问题 prefill 中的高精度读取能影响稍后所有 decode 的文本状态；decode 中的额外高精度读取则作用于当前及后续新增状态。当前“只精化prefill”的质量缺口说明前者不是全部。

已测risk选择质量较好却耗时更高。下一支实验将prefill的选择掩码在当前问题后续decode复用，并分别测prefill是否全精化、残差覆盖比例和全局预算。它同时检验状态形成收益与选择摊销收益；新增mask/控制状态及选择费用全部计入，不预设这条一定成功。
