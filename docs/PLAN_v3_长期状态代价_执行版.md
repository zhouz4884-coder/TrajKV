## 1. 中心命题（收紧后）

> **在固定存储与读取预算下，一次视觉 KV 精度决策的价值，不由它当前轮造成的读出误差决定，而由它污染的历史文本状态在未来若干轮继续造成的损失决定。若这两者的排序不一致，现有以平均失真/当前敏感度为目标的分配方法就可被系统性改进。**

这句话里有三个可以独立判死的部分，必须分开验：

| 代号 | 命题 | 死法 |
|---|---|---|
| **C1** | 精度决策存在**不可忽略的长期代价**：当前轮读出误差之外，还有经历史状态延续的损失 | τ ≪ 1 或 CI 跨 0 |
| **C2** | 长期代价与当前轮读出代价**排序不一致**（当前误差是坏代理） | 二者秩相关高 → 无改进空间 |
| **C3** | 这种不一致可以在**决策时刻**用廉价信号预测，并转为等成本下的更优分配 | 需要未来 query/答案才能判 → 不可部署 |

C1 是"有没有现象"，C2 是"现象是否改变优化目标"，C3 是"能不能变成方法"。**只有三条都过，才有论文。** 任一不过，按 §9 处理，不硬撑。

### 1.1 核心量：精度的时间杠杆 τ

对候选配置 $c$（如 K2V2 / asym_sign / native4）、轮次 $t$、会话 $s$：

$$\Delta^{\mathrm{dir}}_t(c,s) = Q_t(\text{ref}) - Q_t(\text{读 } c,\ \text{历史 ref})$$

$$\Delta^{\mathrm{hor}}_t(c,s) = Q_{t+1..T}(\text{ref}) - Q_{t+1..T}(\text{只在 } t \text{ 用 } c,\ \text{此后读全 ref})$$

$$\boxed{\ \tau_t(c) = \frac{\mathbb{E}_s[\Delta^{\mathrm{hor}}_t(c,s)]}{\mathbb{E}_s[\Delta^{\mathrm{dir}}_t(c,s)]}\ }$$

- $\Delta^{\mathrm{hor}}$ 必须用**同一文本双来源状态注入**测（§2），否则混入"t 轮答案文本不同"这一合法但非机制的差异。
- 同时报 $\Delta^{\mathrm{hor,free}}$（自然自由生成，文本会变）作为**应用意义**版本；$\Delta^{\mathrm{hor,state}}$（文本固定）作为**机制意义**版本。两者之差 = 文本分歧的贡献，本身就是一张图。
- τ ≈ 0：当前读出误差就是全部代价，现有方法已经最优，本项目终止。
- τ ≈ 1：精度的一次投入与它当轮的代价等值，长期账本只是把同一个数摊开。
- **τ > 1 是最有价值的区域**：当前几乎无损的读取，因为改变了被复用的状态，造成不成比例的后续损失。这正是你提出的那个直觉，也是唯一值得为之设计方法的区域。

## 2. 仪器 P0-0：同文本双来源状态注入

这是全项目的支点，也是 P213 缺的那块。P213 比较的是**两条完整轨迹**（上一轮长度 215 vs 195 token），文本、长度、位置全都变了，因此它只能支持"策略影响后续事实归属"，不能支持"数值状态独立传播"。

### 2.1 为什么可以做到"同文本"

关键观察：视觉页 KV 与文本位置 KV 在缓存里**位置可识别、可分别替换**（`p108` 已验证就地写回无 FP16 残留、allocator 零字节误差）。因此可以构造"文本 token 完全相同、只有状态来源不同"的缓存：

1. 压缩分支跑到第 $t$ 轮，得到回答文本 $T_t^{c}$ 与其缓存状态 $\mathrm{state}^{c}$（在压缩视觉条件下计算）。
2. 取**同一串 token** $T_t^{c}$，在 $\mathrm{ref}$ 视觉条件下做一次 teacher-forced prefill，得到 $\mathrm{state}^{\mathrm{ref}|T_t^c}$。
3. 两者 token 相同、位置相同、长度相同；差异只在注意过的视觉 KV 不同所导致的隐藏状态。

于是 2×2 分解成立（$t{+}1$ 起）：

| 臂 | 当前读 | 历史状态 | 含义 |
|---|---|---|---|
| A | ref | ref | 参考 |
| B | $c$ | ref | **直接读出代价** |
| C | ref | $c$ | **历史介导代价**（核心） |
| D | $c$ | $c$ | 交互项 |

选 C 臂 = 把 $c$ 分支缓存里的**视觉页 KV 替换为 ref 值**，保留其文本位置 KV。选 B 臂 = 反向替换。

### 2.2 必须做的两个零假设对照

没有这两条，§3 的门全都是空的。

| 对照 | 构造 | 通过标准 |
|---|---|---|
| **N1 替换无害** | 把 $c$ 分支的视觉页与文本位置 KV **全部**替换为 ref 值 | 与纯 ref 轨迹的 logits 最大差 < 1e-3，token 序列完全一致 |
| **N2 可复现** | 不做任何替换，重跑 $c$ 分支 | 与原始 $c$ 轨迹 logits 最大差 < 1e-3 |

N1 不通过 → 替换机制本身引入扰动，τ 全部作废（这一条最容易被忽略，也最容易致命）。
N2 不通过 → 执行不可复现，先修 P0-B 的语义一致性。

### G1｜量级门（决定 C1 死活）

- 判据：存在 $(c,\ \text{tensor 子集})$ 使得 $\Delta^{\mathrm{hor,state}}$ 的**会话级配对 bootstrap 95% CI 下界 > 1.0 pp**（答案准确率）。
- 且 $\tau \ge 0.5$。
- **死法**：所有配置 $\tau < 0.2$，或 CI 跨 0 → 长期代价不可测，停止这条线，转 §9。

> 为什么是 1.0 pp：低于此的效应，在两个模型的跨架构一致性上都站不住，也撑不起方法章节。这个数字可以商量，但**必须先定**。

### G2｜遗漏门（决定 C2 死活）

同一条多轮标定集、同一候选编码库、同一搜索预算，比较两个目标：

| 目标 | 定义 |
|---|---|
| $J_{\mathrm{avg}}$ | 只用当前轮读出失真（现有做法，但**用多轮数据标定**） |
| $J_{\mathrm{traj}}$ | 当前轮失真 + $\tau$ 加权的长期项 |

- 判据：$J_{\mathrm{avg}}$ 所选配置的会话级损失 $\ge 1.3 \times J_{\mathrm{traj}}$ 所选配置，且配对 CI 不含 0。
- **这条是你自己提出的公平性要求，必须写进协议**：$J_{\mathrm{avg}}$ 也用多轮标定数据。否则"多轮覆盖带来的收益"会被误记成"轨迹目标的收益"。
- 死法：两者等价 → C2 不成立，说明平均目标已经够用，方法无意义。

### G3｜方法门（决定 C3 死活）

- 资源口径：等**实际字节**（含元数据、对齐、编码开销、峰值），等读带宽；不用 logical ratio。
- 判据：在最强基线之上 gap closure $\ge 30\%$ 且 gap $\ge 2$ pp；在独立自由生成测试上同向。
- 注意：FP16 是**任务参照**，不是准确率数学上界；gap closure 的分母写"任务参照"并在正文注明。
- 死法：只在标定集赢 → 方法不成立。

## 5. 如果 G1、G2 都过，方法长什么样（暂定，不许提前实现）

只保留一个最简机制，其余全部作为消融：

**机制假设 M1：误差的出口是文本 KV，不是视觉 KV。**
所以精度应该加在"由被污染视觉条件生成的文本状态"上，而不是加在视觉 KV 本身。可检验预测：在同样的字节预算下，保护文本位置 KV 比保护视觉 KV 更能降低 $\Delta^{\mathrm{hor}}$，但两者对 $\Delta^{\mathrm{dir}}$ 的作用相反。

这个假设如果成立，会得到一个反直觉的结论：**视觉 KV 可以压得更狠，代价转移到文本状态上再补回来**——这恰好是现有"视觉 KV 压缩"文献都没做的账。

同时保留两个候选工具，但只有当它们被 §3 的证据链选中时才实现：

- 按 $\tau$ 加权（而非按平均失真加权）的分配目标；
- 双预算：存储精度与读取精度分开（注意 ERRATA E3：阶段切换只省读带宽，不省存储，别重复犯）。

## 8. 为什么不先"复现别人、看差距"

三个理由，按重要性排：

1. **那个差距测的是你已经怀疑是错的度量。** "FP16 vs 最强低比特"的差距 = 当前轮读出误差的后果。而 C1 的全部内容是：当前轮读出误差**低估**了精度的真实代价。先量这个差距，等于用一个可能失真的尺子去校准另一把尺子。
2. **它不产生决策信息。** 就算复核出"KIVI2 距 FP16 只差 0.8pp"或"差 4pp"，你下一步的动作完全一样：还是要做 P0-0 去量 τ。所以它不是关键路径。
3. **它是论文阶段的成本，不是探索阶段的成本。** 复现强基线是为了"主表可信"，那要等到你知道主表要放哪几行。现在做，大概率白做。

**但它必须做，只是要限时、限量、放并行轨**（§4）。复现失败的标注规则沿用 watchlist §5：跑不通就标 `† mechanism-port` 并写清移植了什么、省略了什么。
