# 共享重建表能否买到更有用的方向信息

这是下一表示实验的成本推导和可证伪目标。底层GPU检查、4输入2步整模梯度小测已经通过；完整校准与独立自由生成尚未完成。下列bit数字是表示计费，不是质量预测或理论最优率。

## 1. 编码和重建分开

当前方向码先减去每层/KV-head的视觉均值，再作归一化Hadamard变换，按4维分组，用固定Gaussian表的256个向量编码。每组一个uint8索引，因此K的payload为2bit/元素。每token另存FP16残差行增益，每层/head保存FP16均值。V采用channel/g128的1bit Lloyd码。

新方案保持编码索引和原行增益的计算规则，将decoder表改为每层/KV-head独立的256×4重建向量。预训练模型权重不变。decoder表可以按真实模型行为校准；它是共享参数，不需要给每个图像元素增加一个bit。

encoder仍需要原2KB表。新decoder表也要计费。行增益仍按固定encoder模板计算，因此学习后的重建可能同时改变残差方向和幅度；不能把它叫作严格的纯方向干预。

## 2. 一个精确的常量预算交换

对本机模型，层数L=28、KV heads H=4、head维度D=128：

| 常量 | 字节 |
|---|---:|
| 原FP32 Hadamard矩阵 | 128×128×4 = 65,536 |
| 固定F16 Gaussian encoder表 | 256×4×2 = 2,048 |
| 新F16 decoder表 | 28×4×256×4×2 = 229,376 |
| 换掉矩阵后净增加 | 229,376−65,536 = 163,840 |

FWHT用7级加减实现同一归一化线性变换，不保存矩阵。实际CUDA小测与独立Torch实现相同；与显式矩阵的浮点误差约2.03e−6。它仍有计算和临时空间，时间不能由矩阵字节数推断。

每个缓存都保守计一次所需encoder/decoder常量，不以多缓存共享摊销来制造低bit。部署若共享表是额外优化，不进入当前基本预算。

## 3. 整体计费

令N为视觉token数，以K/V合计元素数`2LHND`为分母。该格式的组成是：

| 项 | 平均bit/KV scalar |
|---|---:|
| K2/V1索引 | 1.5 |
| K的FP16行增益 | 8/D = 0.0625 |
| V的两槽F16/g128元数据 | 16/128 = 0.125 |
| 每层/head K均值 | 8/N |
| 一条共享视觉位置向量 | 32/(LHD) |
| Gaussian encoder表 | 8192/(LHDN) |
| 全部headwise decoder表 | 64/N |
| 可选V gain/center共享F32参数 | 32/(DN) |

因此，含可选V参数的headwise方案为

`b_head(N) = 1.689732142857 + 72.821428571429 / N`。

例如N=1792时约1.73037，N=768时约1.78455。N=256则约1.97419，不能直接说所有图像都低于1.8。

当前实现对小图选择compact全局decoder，不分配headwise表，其保守计费为

`b_global(N) = 1.689732142857 + 8.821428571429 / N`。

N=256时约1.72419。分支由N和格式尺寸决定，encoder/decoder均可推知，不需要额外token级mask。最终仍以实际tensor owner核验，而不是只用这些算式。

## 4. 质量目标来自使用过程

单纯把重建表拟合到原始K的MSE，未必保存模型实际看到的query投影。当前校准用固定cal32图像、83个问题输入，以FP16教师自生的前最多8个答案位置为目标，优化输出KL；不输入标准答案。

冷状态臂让完整问题经压缩前缀形成，暖状态臂固定原生问题历史。两者分别检验状态条件。另以只学K decoder表/同时学V现有元数据做2×2，防止把V修复误记为K方向收益。

训练forward采用实际packed attention输出，反向用dense straight-through导数。已在4输入2步整模小测上验证forward一致、码本梯度非零且有限、基础模型参数没有梯度。它不构成泛化或准确率结论。

## 5. 实验如何回答问题

先比较compact全局书与重复相同内容的headwise书，核对仅改变表布局时输出一致。之后比较同成本未学习headwise书、冷/暖条件学习书、是否联合V元数据；最终使用真实packed完整模型自由生成。

已经运行的Doc256不再作为后来方法的盲确认。新方案先在开放dev64选择，再进入预先冻结的另外128份源文档、501问。接受质量提升、无提升或跨域退化的实际结果。

可借鉴的已知部件包括旋转/VQ、损失感知量化、冻结模型行为目标，见[本轮文献补查](LITERATURE_UPDATE_2026-11-14_CODEBOOKS.md)。我们要检验的是这些部件在视觉前缀状态形成、实际字节约束和完整GPU模型中的组合效果。
