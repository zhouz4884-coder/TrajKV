# 从电平修复到状态匹配：TrajKV 本轮研究发现

当前证据支持的主线是：**视觉 KV 的低比特损伤，既取决于表示保存了什么，也取决于后续文本状态是在何种精度的视觉前缀上形成的。** 两个条件共同决定端到端答案；仅看逐元素误差、范数或当前注意力输出，无法替代完整模型实验。

本文汇总已完成的独立 DocVQA 确认、外部 TextVQA 复测和固定输出端到端计时。下一阶段六臂GPU校准已启动，使用独立源文档，不以当前确认集继续冒充新确认。

## 1. 这轮实际验证了什么

模型是完整 InternVL3-8B-hf，Qwen2 语言骨干，28 层、4 个 KV heads、每 head 128 维，统一 FP16，在自有双 RTX3090 上进行真实 CUDA 推理。Windows 本机只承担传输、汇总和绘图。压缩候选使用真实 packed KV；材料化原型和 oracle 单独标注。

主工作负载：先形成可复用的图像前缀并压缩，再接收问题。为构造相同的因果图像前缀，程序先执行原生 image+question prefill，但丢弃所有图像之后的问题状态，随后通过压缩前缀重新处理完整问题。第一答案 logit 不与 FP16 共享。首问之后继续自由生成，同一图像最多六问，历史答案不会用标准答案替换。

旧 100 张开发图像中，前 20 张用于无标签校准；候选选择使用另外 80 张。方案冻结后，在图像不重叠的新 64 张文档上确认，共 286 个问题、33 个配置、2112 次自由会话、9438 条计分答案。六个主比较和强质量参考在新图结果产生前固定。

独立核验完成：2112/2112 覆盖，210 项冻结来源比较，1792 项独立存储公式核验，0 个错误。完整记录见 `results/frozen_confirm64_analysis/`，核验见 `audit/a2/FROZEN_CONFIRM64_AUDIT.json`。

## 2. 洞察一：一比特失效有很大的可修复部分，但不是单一范数问题

在确认集上，K/V 都采用 1-bit Lloyd 时，ANLS 为 30.48。保持 packed 索引和格式不变，围绕现有两电平中点匹配去中心 RMS 后，ANLS 为 60.15。两者实际视觉存储均约 1.252 bit/KV scalar。这证实了“同样一个 bit，重建常数能造成很大端到端差别”。

该操作不等于恢复每个 key 的真实范数：它折叠每层/KV-head 的正增益到原有 FP16 scale/minimum，保留码字与中点；非零中点存在时，整体 key 方向也会改变。因此不能将这 29.67pp 全归因于“长度修复”。

更干净的范数×方向干预将 V 固定为 FP16，K 的四臂都材料化为 FP16：

| K 的干预 | 新64 ANLS |
|---|---:|
| 量化范数 + 量化方向 | 51.03 |
| 真实范数 + 量化方向 | 66.49 |
| 量化范数 + 真实方向 | 85.05 |
| 真实范数 + 真实方向（Full） | 87.95 |

真实方向臂比真实范数臂高 18.56pp，95% 图像配对区间 [13.86,23.74]pp，六主比较 Holm 校正后仍显著。方向更重要，但范数单独也值 15.46pp，不能写成“长度无关”。四臂有交互，不能用差值计算“方向解释百分之多少”。

数学上，注意力误差由实际 query 看到的投影 `qᵀε`、候选 key 的间隔以及视觉段/文本段的相对偏置决定。元素 MSE、角度和 SNR 各自只描述部分条件。`SNR>1` 或 `SNR>5` 不是这里的普适可用性门槛；1.25、1.31、1.09 也只是若干编码成本点，而非理论最优码率。

## 3. 洞察二：校准必须匹配文本状态的形成方式

我们只优化 224 个量化因子，模型权重全部冻结，不使用标准答案，目标来自 FP16 第一答案词表分布。因子在编码时折叠进既有量化元数据，decoder 不保留额外系数 tensor。

两种校准使用相同参数量、相同旧图和优化条件，区别在于问题状态通过哪个前缀形成：

| 方法 | 约 bit/scalar | 新64 ANLS |
|---|---:|---:|
| 原生 K2/V1，min/max | 1.752 | 65.96 |
| K2 + per-channel Lloyd V1 | 1.752 | 78.98 |
| 原生问题历史条件下校准 | 1.752 | 74.40 |
| 压缩前缀重新形成问题状态后校准（冻结主候选） | 1.752 | 81.13 |

状态匹配版比原生历史版高 6.73pp，95% 配对区间 [3.33,10.46]pp，预定校正检验支持该差别。相对强 Lloyd 对照高 2.15pp，但区间 [-0.14,4.49]pp，当前确认尚不能断言胜过它。

这一区别有实际任务含义。image+question 联合 prefill 后再压缩，以及压缩好的 image prefix 接收新问题，是两种合法工作负载。前者的问题 KV 已读过高精度图像；后者需要通过压缩图像形成问题 KV。相同问题 token 并不意味着相同隐状态。我们目前关注后者，应按其实际状态过程做校准和评测。

第一问的独立连续指标共 448 条，采用固定 canonical 参考答案的 teacher forcing：

| 方法 | FP16→方法 KL | 参考 token 平均 log-prob |
|---|---:|---:|
| FP16 | 0 | −0.605 |
| 原生 K2/V2 | 0.115 | −0.765 |
| 方向码 K / Lloyd V1 | 0.157 | −0.767 |
| 状态匹配校准 | 0.216 | −0.819 |
| K2 / Lloyd V1 | 0.281 | −0.941 |
| 原生历史校准 | 0.287 | −0.914 |
| 一比特 Lloyd + RMS | 0.882 | −1.512 |

这些是分布代理，不计作任务准确率。它们与自由生成共同提示：第一 token 校准有效，但还没有控制完整答案轨迹及多问题状态。

## 4. 当前资源—质量结果

| 方法 | 实际视觉 bit/scalar | 新64 ANLS | 角色 |
|---|---:|---:|---|
| FP16 cap8 | 16.002 | 87.95 | 质量参考 |
| 原生4-bit | 4.252 | 88.48 | packed 对照 |
| 原生 K2/V2 | 2.252 | 85.13 | packed 对照 |
| KVarN2 数值质量端口 | 18.39 | 85.95 | 同时持有重构与参考代码，不能列作低存储部署点 |
| 方向码 K / Lloyd V1 | 约1.705 | 82.56 | 冻结次要候选，真实 packed |

存储包含 payload、量化元数据、位置、增益、所需 decoder 常量；共享 encoder 校准常量另列，并在预算资格中保守计入。FP16 分数不是准确率上界，量化方法高于 FP16 并不构成算术矛盾。

**预定“≤1.8 bit 且距强参考不超过 0.5pp”的质量目标未达到。** 主候选比冻结 KVarN 质量参考低 4.82pp，95% 配对区间 [−8.36,−1.35]pp。方向码次要候选的点分数更高，但也没有达到目标，不能事后替换主候选宣称确认成功。

## 5. 读轴有可用空间，下一步测剂量与阶段组合

所有读取策略持有完全相同的 cap16 base+residual 存储，所有 base 视觉 token 保留。相对全精化：

| 策略 | 额外逻辑读量节省 | ANLS 差值 |
|---|---:|---:|
| risk proxy | 78.56% | −0.590pp |
| mass | 78.48% | −0.877pp |
| 只精化问题 prefill | 85.79% | −1.444pp |
| 周期精化 | 75.03% | −2.004pp |
| 随机 | 78.73% | −2.359pp |
| 不精化 | 100% | −3.541pp |

risk 的总逻辑 KV 读量节省为 30.05%。它离预定 0.5pp 点容差差 0.09pp，当前不算达标，区间也不足以证明非劣。指标是实际调用的声明 tensor payload 与选择费用，不能改称硬件 HBM 流量。自由生成长度不同，延迟另以完全相同输出 token 测量。

结果支持继续测更高读取剂量、prefill 保底和按影响选择的组合。它没有支持“只保护 prefill 就足够”，也没有支持“动态选择一定不如周期”。接下来按新开发数据调整，当前64只保留为已观察结果。

## 7. 继续探索的具体方向

先推进**状态匹配 × 答案轨迹校准**，保持真实 packed 格式和 decoder 不变。将第一 token 词表 KL 扩展为 FP16 自生答案前若干 token 的 KL；同时比较压缩问题状态和原生历史条件。再比较只学 scale 与同时学 center，全部折入已有 scale/minimum，单独消融初始化、校准条件和参数量。

下一轮原始 DocVQA 验证集来自固定公开版本。旧1000题与前1000行逐题和答案完全对齐；排除它们涉及的全部212个UCSF源文档，再按源文档ID哈希划分：32校准文档125题、64开发文档255题、256确认文档999题。每源文档只选一页，组间不共享源文档。图像保留原始编码字节。该划分不使用任何模型分数，后续确认仍在方法选定后才执行。

支线保留两条：在新开发文档上测读取剂量与phase/impact组合；用受控文本 KV 干预检验高精度问题状态是否承载可转移视觉信息。后者若成立，可进一步研究预算内少量高精度状态与低比特视觉前缀的组合，新增状态字节必须计入。

相关部件有明确前人基础：[KIVI](https://proceedings.mlr.press/v235/liu24bz.html)提供轴向非对称的出发点，[CalibQuant](https://arxiv.org/abs/2502.14882)提供校准与量化实现参照，[NOVA-KV](https://arxiv.org/abs/2608.04074)等研究query相关失真，[ReadKV](https://arxiv.org/abs/2610.11245)已有读取精度轴。我们要验证的新增部分，是相同低比特表示在不同状态形成条件下的端到端差别，以及针对这一条件的低成本修复。组合部件应逐项消融，让最终方法的收益有清楚来源。
