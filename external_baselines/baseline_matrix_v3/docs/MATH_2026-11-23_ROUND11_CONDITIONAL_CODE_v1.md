# Round11：条件最优编码与空间预测的数学范围

本文件说明执行稿v1的可证明部分；不从重构误差推出VQA分数。完整实验结果在阶段报告单列。

## 同一份位流中被分步优化丢掉的自由度

对一个128维V token，R7在固定Half端点l0/l1下存base bit b、残差sign s和共享非负Half幅度alpha。可用的重建集合为 l_b + s*alpha。顺序最近邻base再拟合残差只找到该集合的一个点；保持端点及原位流容量不变，可以联合选择b/s/alpha。

忽略最终Half舍入，令每通道到两个端点的绝对距离为u<=v。对给定alpha，四种base/sign组合的最小误差是min((u-alpha)^2,(v-alpha)^2)。每通道仅在alpha=(u+v)/2切换。将128个阈值排序，最多129个区间；区间内目标为固定二次式，其最优幅度为所选距离的均值投影到该区间。扫描这些候选得到这个实数内层的全局最优。实际编码再比较原alpha、最优值的Half舍入和相邻Half；按实际Half重建的float64 SSE严格改善才替换，平局保持旧字段。

这证明实数内层求解与实际编码的局部不增SSE，未证明整个Half幅度域全局最优。旧alpha/实际旧字段被包含，因此也不依赖高斯假设、SNR阈值或未来问题。它不保证attention输出、logit KL或自由答案不下降。

## 模式位购买一个条件预测器

残差参数化r=alpha*s本来具有(alpha,s)与(-alpha,-s)表示同一残差的二元对称。R7选择alpha非负作为规范形式，但其存储槽仍是完整FP16，因此符号位没有承载独立幅度信息。本轮把这个规范冗余重新赋予预测器选择语义：不是增加一个免费残差bit，而是用既存冗余字段在两个条件重建族之间选择。它增加解码器表达能力，也增加计算；完整持久容量不增并不意味着运行时间免费。若空间预测有效，下一阶段才值得研究幅度精度与更多预测模式之间的交换。

FP16非负alpha的符号位未用于幅度。保留其15位幅度，通过该位在原base预测器与邻域base预测器之间切换。旧重建仍是合法候选，因此本轮无需额外持久张量或元数据。负零按整数位解释为mode1；K残差不采用这种语义。

同32-token packed word对应原生16x16网格中的两行。预测器权重为中心1/2、左/右各1/8、配对行同列1/4；水平边界回退中心。邻居全部来自既存base字段，且每个tile/thumbnail独立。JointSpatial必须先写完最终base再预测，避免对同一份位流同时引用两份base。Shuffled以固定解析置换共轭同一邻接图，保留权重、度数和字节；它与Spatial的直接对照检验空间结构，而与JointSpatial的比较同时混有联合重编码因素。

## 为什么任务损失可以和局部SSE反向

固定某层某query的K路由时，输出误差为sum_i,h a_hi W_h e_i。元素SSE优化的是sum_i ||e_i||^2，忽略W_h的方向、token间交叉项以及后续层状态。即便所有覆盖token局部SSE都变小，误差方向或抵消关系改变仍可能使输出更差。因此本轮完整任务判决必须使用自由答案，不能用SSE或单个校准样本的KL充当效果。

若完整D96支持继续，可在已授权有界分支采用模型自身的读出几何：H=sum_h W_h^T W_h，其中h为该KV head对应的GQA query heads。对固定预测p与sign s，未舍入alpha的条件最优为max(0,s^T H(v-p)/(s^T Hs))（分母为0时保留原）。这是一维条件解，sign的联合离散最优并未被解决。H给出了对单token读出误差的query无关Cauchy界的几何部分，不是完整模型任务Hessian；不能宣称闭式最优任务编码。H若只在编码时从原W_O生成并释放，应记临时峰值及编码耗时；若常驻则必须计入完整字节。是否实施由D96真实任务及成本决定。

## 论文贡献需要补足的实验事实

本轮希望看到同一原B0在至少两个域产生一致的任务改善，再用独立R128确认。联合重编码与空间预测分别消融，Spatial必须胜过同预算Shuffled才能将收益归于空间结构。若只降低SSE而没有更好的真实答案，当前实现仍是可复核的负结果，不能作为高水平论文的主性能贡献。
