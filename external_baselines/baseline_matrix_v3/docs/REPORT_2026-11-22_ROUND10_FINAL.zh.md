# Round10：局部重构改善与真实任务收益的端到端检验

2026-11-22。研究评测已完整结束；GitHub发布身份由独立交付回执记录。本轮仍保留原R7低、高两档为主干，尚未得到可稳定替换它们的新版本。

新来源复测中，V128-R43相对R7低档在InfoVQA增加0.9615个百分点、DocVQA增加0.7960个百分点，TextVQA和ChartQA持平；完整视觉owner增加约8.9%，码率约1.41bit/elem。正向变化来自3题改善、1题损伤，不是所有域上稳定提分，也不是同1.3bit预算收益。开发集Text的+2.6563个百分点没有在新Text64上复现。以下保留全部结果，不把小幅正向线索写成已确定的通用优势。

两张RTX3090运行完整InternVL3-8B与实际packed reader；模型、数据、结果以及新编译/临时缓存使用远端项目8TB数据盘。本地大体量取回、分析、归档使用E盘。原R7资产、冻结结果和已有四域500任务没有覆盖或重跑。

## 最重要的研究认识

1. LS-FZ降低了真实完整模型校准KL（0.0333633至0.0290374），但D160四域任务均分没有增加。Text有2题改善、1题变差，净0；不能把净0写成逐题恒等。
2. KRA确实改动了约84.0812%的K23残差alpha，共5,262,824个元素；指定H误差按来源等权下降0.324714%，部署值没有H误差变坏token，但160题输出token和答案均与R7低档完全相同。这不是实现未生效，而是当前坐标目标的微小改善没有改变任务输出。
3. FB0在8个既有fit来源的固定状态CPU机制重放中降低了局部读出误差，却未在D160获得任务收益；窗口反馈W64还提高了元素与投影输出误差。窗口carry恒等式必须含终端项，不能用跨token均值误差下降代替实际attention读出改善。
4. V128与AddOldOrder在近同存储上限下出现不同域间取舍；V128还包含真实V残差重编码，所以该对照比较的是两个明确表示包，不能把全部收益单独归因于group大小。下一步不依据已暴露的小集反复挑层或换参数。

对K，固定query时delta-z=q^T delta-k/sqrt(d)，但一阶读出变化还含sum_i a_i delta-z_i(v_i-o)。只优化逐token的二次K误差没有覆盖V、softmax跨token耦合和新增文本状态。对V，固定sign、非负约束未激活且忽略Half时，RE后的base导数为I-ss^T/128；实际sign切换、约束与舍入使它只是一条局部分片公式。数学条件最优、校准KL与真实答案三个层次必须分别验证。

本报告仅覆盖已完成的56个实际run、2496次新增free回答。D160开发面板为40个run/1600次，reserve224固定候选复测为16个run/896次；80个声明view共3456事件，其中960是共用参照，不是额外推理。Teacher生成、TF、fit capture与QA0控制另列，不计入free回答。

固定V128-R43在reserve224相对R7low的Text/Info/Doc/Chart变化为+0.0000/+0.9615/+0.7960/+0.0000 pp。这是单独复测cohort的域内差异，下面分别给出配对区间、完整容量和计时；开发结果不与之混合。

## 方法

先在D160 development比较原生FP16、两档冻结R7、四个V候选、两个中档和KRA1。Root在读取reserve模型输出前冻结仅V128-R43进入复测。V128保留K23和原f0，将V改为g128并重编原20V残差；AddOldOrder把近同费用用于原ranking更多槽；KRA只改原K23 alpha且另计5980B。机制证据不充当task因果证明。

## 校准事件与局限

原cal64复用48fit+16select闭合证据：teacher64源/285token，实际selection fullTF208次，精确字段复用16次，selection student outer forward936次；另有fit capture 134次outer forward。KRA另复用48fit而未重新capture，16select teacher72token，64个候选fullTF加1次原R7 identity TF、共292次student outer forward。完整事件表保留额外技术控制，不与free回答相加。

D160用于选择，reserve224是冻结候选的单模型、指定cohort复测；不替代正式500全split、跨模型验证或canonical SourceRun准入。各域、各cohort均分别报告；配对CI为描述性未校正区间，跨0不是等价，不跨0也不自动成为算法胜者证书。私有native/teacher logits/PCA输入没有在此重放，来源身份与公开标量核验的边界保留。

## 下一步判断

优先补一个有信息量的对照：保持原K、V粒度、43覆盖及同224个V参数，直接对实际C_theta、硬RE和真实packed完整TF后缀目标做有界成对优化。R10用完整suffix选择lambda/W，没有用该目标优化theta，因此完整状态校准路线尚未被检验。用相同更新预算的局部目标随机方向优化作控制，区分“换优化器”与“目标/状态和部署一致”。具体公式、计费与对照见[下一阶段提案](../results/round10/next_proposal_v1/PROPOSAL_2026-11-22_Round10后_实际压缩完整后缀目标_v1.md)。该提案没有启动GPU，也不计作本轮成果。

若只有KL改善而新来源自由回答仍无收益，应停止扩大这一224参数族，再基于历史明确的新表示自由度设计研究。保留已验证R7两档作为论文与后续跨模型的主干，不因为这一轮增量方案没有稳定胜出就丢弃原方法。

残差换局部g128是既有提案，可行成本为每层16N-2048B、一条sign残差18NB，剩2N+2048B还须支付真实flags/offset。该算术不是质量最优定理，R9也已经实际做过基码-残差交换；不将旧构件重新命名为创新，不依据本轮约9%额外容量的小幅收益立即扩大同族。
