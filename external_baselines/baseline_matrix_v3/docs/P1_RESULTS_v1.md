TextVQA采用MMF十票soft accuracy；InfoVQA主指标采用冻结Qwen-VL vendor ANLS，规范化长度ANLS另存诊断，不声称已核实今日RRC服务器代码。所有质量保留原始字符串，不按预算、题目难度或输出长度挑子集。

字节含真实payload、量化元数据、位置索引、共享/逐层encoder常数，按底层storage去重。表中是每问有效bit的均值，ratio-of-sums值、最小/最大值与超预算题数另在CSV/JSON。K的非128倍数尾部保留FP16，因此M2/M3不能以“名义2bit”冒称2.25bit。E的固定保护窗在少量短视觉前缀上抬高实际预算；M1 Info平均1.8010bit、最大4.0647bit，并非每问都满足1.8bit。

C1是官方算法的显式FP32 bias归约视觉移植，当前仅M1进入试评；原FP16溢出版本、C2待验证证据保留。E是query-unknown视觉前缀选择，不利用未来问题，短前缀可能采用源代码SnapKV fallback。T是0xSero第三方实现，不能标Google官方或原论文完整配置。

M1 Text的K2较FP16高1.797pp，配对95%CI为[-1.016,4.609]pp，小样本波动尚不能解释为提升；M1 Info差-3.947pp，CI[-8.598,0.463]pp。逐格source-cluster bootstrap与sign-flip结果保留，未做多重比较校正的p值不能直接用作显著性宣称，CI跨零也不代表等价。

当前wall/TTFT包含审计、同步与streamer，且输出长度不同，均为质量试验中的原型耗时，不能当作受控速度排名。后续需同环境交错、预热和固定工作负载的性能测量。
