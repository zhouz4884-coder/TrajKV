# 视觉子集压缩：注意力总量与子集内部路由

状态：代数分析及已有诊断解释。当前执行目标仍是建立外部基线库；此文没有启动新算法实验。

## 1. 固定一个原生查询的精确分解

设视觉位置集合为 V，文本集合为 T，查询 q 固定，分数为 z_i=qᵀk_i/√d。定义

Z_V=Σ_{i∈V}exp(z_i)，Z_T=Σ_{j∈T}exp(z_j)，s=Z_V/(Z_V+Z_T)。

视觉内部条件概率为 π_i=exp(z_i)/Z_V，文本内部条件概率为 τ_j=exp(z_j)/Z_T。令 m_V=Σπ_i v_i，m_T=Στ_j v_j，则原注意力输出恰为

o=s m_V+(1−s)m_T。

仅视觉 K 被压缩时，将误差写成

e_i=β(q)+η_i(q)，其中 β(q)=qᵀ(mean(K̂_V)−mean(K_V))/√d，Ση_i=0。

不需要高斯、独立或小噪声假设，就有

ΔlogZ_V=β+log E_π[exp(η)]，

ŝ=sigmoid(logit(s)+ΔlogZ_V)，

π̂_i=π_i exp(η_i)/E_π[exp(η)]。

这里的 E_π 是该次注意力的有限加权求和。均匀平均为零的 η，并不保证其注意力加权平均为零。

β 不改变视觉内部排序，却改变视觉与文本之间的总权重。η 同时改变视觉内部路由和视觉分区函数。对所有 K 加同一常数向量的 softmax 平移不变性，不能直接用于只处理视觉集合的编码。

## 2. 输出误差的两个可分辨来源

文本 K/V 保持精确，视觉 V 可有误差。固定 q 时，精确恒等式为

ô−o=(ŝ−s)(m_V−m_T)+ŝ(m̂_V−m_V)。

第一项是视觉/文本竞争改变，第二项是视觉内部的路由及内容改变。进一步有

‖ô−o‖ ≤ |ŝ−s|‖m_V−m_T‖ + ŝ[‖Σ(π̂_i−π_i)v_i‖ + ‖Σπ̂_i(v̂_i−v_i)‖]。

sigmoid 的全局 Lipschitz 常数给出 |ŝ−s|≤min(1,|ΔlogZ_V|/4)。如果 η 的极差为 R，条件分布的总变差有界于 tanh(R/4)；这个界约束视觉内部重加权，而不能代替对 β 的测量。

上述是固定查询、单层的说明。数值内核误差需要另列残差，K/V 存储精确也不等于点积与归约算术精确。真实压缩前向中，前面层改变会继续改变后面查询；原生查询的教师控制需要与真实压缩分支的查询漂移分开报告。对 V 的固定查询线性误差，也不能推出其端到端影响始终局部或不传播。

## 3. 驱逐同样改变分区函数

若保留集合 S⊂V，保留项使用原 K/V，且没有额外补偿，则

Ẑ_V/Z_V=Σ_{i∈S}π_i，

ΔlogZ_V=log π(S)。

未来查询的保留注意力比例 π(S) 不等于保留 token 数比例 |S|/|V|。所以仅凭 token 保留率，不能推导未来任务质量，也不能把任意确定性选择器加上 log(|V|/|S|) 当作普遍无偏修复。

原 P1 的512条 W64/.888 已测请求均触发所选 NVIDIA 实现的 SnapKV fallback。W8 在部分长度上会进入真实 pyramid 层预算；这两个源码设置需要分别测量，不能由旧 W64 的低分判定论文窗口配置。

## 4. 现有四源诊断支持什么

真实 M1 四源、五层诊断中，层0的整层视觉 K 均值能量占比约99.86%–99.88%。这不是每个 head 都有同一比例。0xSero uniform-prod 端口的全局 K cosine 约0.918，但原生查询下的中心化 logit 噪声/信号约5–6；视觉总权重约从0.21–0.26升至0.77–0.94。

原 packed reader 对独立解码参考的单层误差约2e−4；恢复源码近窗及提高 V 位宽，没有在这四个例子中恢复自然正确答案。这支持继续分别测量均值项、对比度项与分区函数，而不是仅按全局 K MSE/cosine判断问题。它也不等于原论文 mixed-channel 配置的性能结论。

这些数据来自 `docs/TURBOQUANT_NATIVE_DIAGNOSTIC_v1.md` 和 `results/analysis/T_native_diagnostic_v1/`，原生 q/K/V 特征保留在远端数据盘。OnlyTerp-MSE 的源算法、参数及读法另立身份，不能用它的结果替换旧 prod 记录。

## 5. 对基线解释与后续研究的作用

当前先完成固定输入下的质量、完整字节和真实时延测量。后续机制对照可将真实均值与量化对比度、量化均值与真实对比度交叉组合，测量视觉总权重与视觉内部路由；这些干预是解释性 oracle，需要与可部署方法区分。

是否值得保留额外均值、改变编码空间或调整计算精度，应由这些控制及冻结外部基线上的真实结果决定。这里没有给出未验证的质量预测，也不把这些通用恒等式本身作为论文新颖性结论。
