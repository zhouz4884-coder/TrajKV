# Round9：精度交换与功能校准的参考来源

2026-11-22。工作流：多源检索及引文核验。学术MCP未挂载，沿用arXiv原文与PMLR出版页直接核验；不将检索摘要当成在本项目重现的结果。当前正式四域500任务保持冻结，本文不启动新算法实验。

| 来源 | 本次核验的构件 | 对当前研究的用途 |
|---|---|---|
| [RateQuant](https://arxiv.org/abs/2605.06675)，arXiv记录 | 针对具体量化器标定失真曲线，再作混合精度分配 | 借鉴“价格和收益必须对实际编码器测量”。我们的基码/残差是离散合法格式，不能直接套连续位宽衰减率。 |
| [GSRQ](https://proceedings.mlr.press/v306/kim26bf.html)，ICML 2026 / PMLR 306 | gain/shape码本学习与残差向量量化，处理质心缩短和方向保真 | 是方向量化与残差组合应引用的工作。我们应实测答案、完整字节和非均匀修正的新增价值。 |
| [KVTuner](https://proceedings.mlr.press/v267/li25dd.html)，ICML 2025 / PMLR 267 | 离线搜索层级K/V精度对，并考虑硬件约束 | 静态分配、按层选精度不是空白；当前可执行动作是同一视觉前缀的基础索引与实际残差池之间交换。 |
| [OptR](https://arxiv.org/abs/2608.02691)，arXiv记录 | 用投影后的attention输出校准旋转，区分K/V误差 | 支持功能目标的重要性，但不能据此预言我们的局部loss降低会改善VQA。 |
| [CALFA-KV §3.2、附录C](https://arxiv.org/html/2611.10511v1#S3.SS2)，arXiv记录 | 联合K/V输出校准；固定索引提议更新后，用实际重编码重放验收 | 可借鉴训练与部署重构一致的设计。我们已做同容量K书与真实索引重编码，尚不能将这一构件本身称新贡献。 |
| [ReadKV](https://arxiv.org/abs/2610.11245)，arXiv记录 | 分开存储预算与逐query读取预算，渐进码按需取前缀 | 两个资源轴已有直接先例。当前Drop4/Exchange主要是存储格式与质量实验，没有在线query读取调度收益。 |

这些工作都可借鉴。创新判断以组合后新增的可测能力为依据，不以“是否只在arXiv”决定继续或放弃。当前最值得写进研究问题的是：固定V和完整预算时，哪种实际K修正能够稳定修复答案；不把更大码本或更低校准KL直接当作答案收益。

我们的固定query KL分解和条件动态规划来自明确局部模型：query、文本KV及原生目标分布固定。该模型可精确求自己的代理目标，真实自由生成仍会更新后续状态。三层方案局部KL更低却没有优于单层候选，是这个边界的实测提醒。

本次来源以作者记录和出版页为准；没有引用异模型的论文分数替代InternVL3-8B的同题GPU结果。当前论文比较表仍应写“已完成的外部对照”，完整实现覆盖和未运行项分别披露。
