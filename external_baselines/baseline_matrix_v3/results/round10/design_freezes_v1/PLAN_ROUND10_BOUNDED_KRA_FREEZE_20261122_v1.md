## 3. 唯一额外同码流容量候选KRA1

V基码、V20残差、K基码、K增益/均值和全部残差sign code不变。只调整原23个K残差单元的FP16 alpha；这会改变base与残差的相对方向，不能等同于把整个K只调长短。

对旧编码器使用的centered-WHT目标x、当前base b、固定符号s，考虑PSD度量H：

`min_(alpha≥0) (x−b−alpha s)ᵀH(x−b−alpha s)`。

在忽略写回Half舍入时，条件最优为：

`alpha*=max(0,sᵀH(x−b))/(sᵀHs)`。

取`H=I+gamma uuᵀ`即可用少量内积计算。它是中心化旋转空间中给定度量的残差拟合最优，不是attention或任务全局最优。

### 离线估计与控制

- 仅从原calFit48私有case中的实际压缩学生q_rotated，估计各selected-K单元的未中心化二阶矩；每来源同权，来源内对实际采集状态和7个GQA query-head平均。
- 取首特征向量u。sigma²=(trace−lambda_max)/127；gamma=clip(lambda_max/max(sigma²,epsilon)−1,0,32)。零能量或非有限/数值失效退回gamma0；lambda_max>0而sigma²=0的纯rank1是合法强方向，按cap得到gamma32，不退回identity。
- u保存实际Half[23,128]，gamma实际FP32[23]。单位次序来自已收费原ranking；新增资产5888+92=5980B，必须按真实storage计费。若实现存储更大，则按实际值收费。
- calSelect16在strength={0,.25,.5,1}上用真实8B完整TF后缀评价，最终非零strength在cal选定并折入gamma；strength0是R7字段身份控制。即使0的校准损失更好，也保留一次有界的非零候选任务检验，不能把它冒称已选出更好部署策略。
- gamma0明确复用原alpha，保证身份控制；非零更新后用实际FP16写入、有限性、V值不变、K基码不变和完整预算核验。

编码部署只用图像原生前缀、固定u/gamma及当前native residual error，不用后来问题的query或答案。原cal GT不进入拟合/选择或编码。
