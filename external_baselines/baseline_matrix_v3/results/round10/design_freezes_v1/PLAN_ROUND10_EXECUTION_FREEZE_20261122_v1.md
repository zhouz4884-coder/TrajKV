# Round10：V重编码与窗口反馈执行稿 v1

日期：2026-11-22。状态：**设计已收敛；本稿不代表新GPU实验已经开始或已有新质量结果。**

## 1. 目标与范围

在M1 InternVL3-8B、未知问题的静态视觉前缀协议下，比较四个V处理与同题FP16、R7低档、R7高档。目标是在原R7低档码流容量附近提高真实任务质量，优先缩小TextVQA/InfoVQA与自家高档的差距，同时检查DocVQA/ChartQA损伤。

本阶段完成标准是四候选的合法实现、真实GPU端到端评测或有证据的恒等去重/具体失败、完整质量/字节/成本报告、后续取舍及阶段公开同步。正向增益是争取的研究结果，不预写成完成事实。

首批不扩大基码位宽、残差数量或覆盖，不修改原K字段、模型权重、图像token数、模板、RoPE/position IDs和已冻结500题执行计划。静态图像前缀编码完成后不随问题重写；本阶段不实现局部图像修改或视觉token增量维护。

## 2. 不变的实验合同

- 局部机制分析固定R7学生q/文本状态，区分FF/CF/FC/CC，K在前、V在后。局部量不冒充完整模型或答案因果归因。
- 自由回答采用冻结M1矩阵的各域生成与主评分器合同；旧R7评分只可另列辅助，不能混成主表。参考答案只进入独立评分。
- FP16/R7低/高参照只跑一次，或复用身份与协议完整匹配的原预测；不为本阶段另跑原生全数据集。

### 3.1 LS提案与共同步长

cal64每域16来源，预先分calFit48（每域12）与calSelect16（每域4）。允许校准材料复用，但记录暴露历史；与开发/复测来源隔离。

固定采集状态、base bits与残差，以`a=g>0, h=g·offset`重参数化。局部仿射部分为：

`V = m + 0.5S + a S(b−0.5) + hS + r`。

围绕实际Half解码点固定舍入余量，按W_O联合输出拟合每层8变量（4 KV-head×2），共224参数；带ridge回缩原V0并施加正gain约束。使用现active-set凸二次求解，不把解后逐坐标clip称为约束最优。

在(a,h)坐标从原V0向提案插值，λ取`{0.25,0.5,1}`。在calSelect用FZ/RE两部署source-balanced完整TF后缀KL的均值选一个共同λ；同值取较小λ。两部署不得各自选择λ。

λ0为R7控制，FZ/RE均应还原原R7。即使λ0校准KL更好，本阶段仍保留一次受控的非零提案任务检验；这不是已选出更优部署策略。真正数学/逐ID物理恒等可去重，不能暗中增大扰动制造动作。

教师答案到EOS、校准cap32；这不替代自由生成的冻结矩阵参数。λ四档含控制的calSelect TF源次为112（λ0共用）或128（不共用），另列教师生成、状态采集及编码费用。

### 3.2 FB-W的窗口与实际电平

每个V元素的A/B须来自原V0、原残差、scale/min及逐级Half加法的**最终实际解码值**。使用FP32距离、carry和固定tie→bit0；第一版不加隐式clipping。

有限窗口`W∈{32,64,128,256}`，在已核验的M1原生256-token图块边界额外reset。另列global，定义为整段视觉序列不重置，复现旧全局FB1；W1逐token reset应严格等于FB0。

窗口选择依据原生图块尺度，而非总tile数量。N256时W256与global可自然相同，按实际ID/字段去重，并报有效窗长、W/256和W/N；不把它当两个独立观测。W1用作控制；其余五种规则中只在calSelect选一个非平凡规则，按全模型TF后缀损失source-balanced最小值，tie优先较短carry。测试阶段不看问题attention选择窗口或重排token。

即使W1的校准KL更好，仍保留一个非平凡规则的有界任务检验。最多6规则×16来源=96次calSelect TF；数值相同分支可复用。

有限窗口用新kernel/source分支实现；确认字/位边界无并发覆盖。global不加tile reset。反馈后**不再RE**，否则所优化的A/B不再是最终解码值。

## 4. 数学解释与诊断边界

固定当前读出权重a，误差ε的条件二阶矩为：

`E[(aᵀε)²|a] = aᵀΣ_(ε|a)a + (aᵀμ_(ε|a))²`。

同误差能量的不同相关结构可能改变读出，但FB处理也可能改变均值与元素MSE；不能将任务增益唯一归因于相关性或ρ。

实数递推`u_t=x_t+c_(t−1), y_t=Q(u_t), c_t=u_t−y_t`，每窗c0=0，则：

`y_t−x_t=c_(t−1)−c_t`；

`Σ_(t=1..W) a_t(y_t−x_t) = Σ_(t=1..W−1)(a_(t+1)−a_t)c_t − a_W c_W`。

实现另记FP32舍入余项和packed reader数值差，不能丢terminal carry或宣称窗口误差和为0。

对多窗定义边界齐全的几何描述：

`H_geom = [Σ_windows (Σ_inner(Δa)² + a_end²)] / Σ_all a²`。

H_geom只描述a。只有额外假设carry零均值、白、方差同质，以及plain误差对应的分布条件，才能近似成损失比，且还需carry/plain方差比。W1给H_geom=1，符合恒等控制。内部差分H可另记，但不称精确收益、上界或一阶最优判据。

H_geom在分母为0时记NA。可记录η作为条件模型残差描述；`1−H_geom≤0`或接近0时记NA，不使用η阈值认证环路、归因失败或放行任务。slew、输入/电平范围及carry自相关均为诊断，不是唯一失效原因或必要/充分稳定条件。

每source记录/汇总：

- carry RMS、path max、terminal、相对真实非零电平间距`|B−A|`的比值；零间距与非有限单列。
- 实际误差均值、MSE/能量、相邻差分、必要的自相关摘要、H_geom、实际加权输出及恒等式余项。
- W_O输出、完整CC相对FF损失、FF/CF/FC/CC条件量；按source归约，不把层/head视为独立图像。
- V及目标输出能量，注明使用的是读出头空间还是W_O后空间；不把`MSE(CC−FC)`冒作V范数。
- 改动bit数量、字段hash、原K不变证明、encode临时workspace/峰值和时间。

使用当前连续token、当前解码电平采集统计。旧g128/stride4归一化dump可作历史背景，不能据lag4差分或corr4反演lag1、不能称保守过载估计。

FB0仅在固定电平、精确距离的理论条件下保证**逐元素重构MSE不劣**，不推出attention、KL或任务非劣。实际FP32距离比较须报告舍入/tie容差及重构误差违反计数，不能把理论实数运算默认为实现的逐位保证。
