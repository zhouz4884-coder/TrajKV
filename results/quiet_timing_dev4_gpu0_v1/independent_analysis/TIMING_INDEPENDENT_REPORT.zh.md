## Probe 与简单控制

- Probe 相对 Periodic 的四会话总时间中位数变化为 **+0.95%**；inter-token 中位数变化为 +1.06%。这是本组固定轨迹上的成本差，不能据此判断答案质量。
- Probe 相对 Current table 的四会话总时间中位数变化为 **+1.47%**；inter-token 中位数变化为 +2.06%。这是本组固定轨迹上的成本差，不能据此判断答案质量。
- Probe 相对 Future table 的四会话总时间中位数变化为 **+1.50%**；inter-token 中位数变化为 +2.02%。这是本组固定轨迹上的成本差，不能据此判断答案质量。
- Probe 相对 Full FP16 的四会话总时间中位数变化为 **+11.79%**；inter-token 中位数变化为 +5.69%。这是本组固定轨迹上的成本差，不能据此判断答案质量。

Probe 的执行探针/升级数为 144/144（跨 12 个测量会话实例），总 forward event 为 372，预算跳过 228 次。已执行探针全部触发，不能把预算截断当成阈值具有选择性。
其额外读取由全部残差读取 13.223 MiB/会话与探针额外 base/text 读取 2.707 MiB/会话组成。probe 总读取本身也含残差，不能再次与残差总项相加。
已执行探针的纠偏 relative-L2 范围为 0.0546–0.1935（中位数 0.1017），均超过固定阈值 0.02。它是 base/residual 差，不是 FP16 真实误差。

| Future table | 24.61% | 34.656 | 34.950 | 118.000 | 64.210 |
| L7 probe (0.02) | 24.61% | 34.656 | 34.950 | 118.000 | 64.210 |
| Margin write | 24.61% | 34.656 | 34.950 | 118.000 | 64.210 |

- Unique owner 是 bank 的实际去重存储，包含常驻视觉表示、文本预留容量和位置；视觉 payload 百分比不能替代整个 KV owner 的百分比。
- 构造后 allocator 增量在独立非计时 warmup 中同步采样，包含该时点仍存活的 setup 张量；它不是严格的 bank-only 量，也不等于最终服务稳态。reserved 是 allocator 保留池，不能当作活跃张量。
- bank.owned 不包含后续 repair_start 快照与临时 workspace；整会话 peak 包含首次视觉 prefill、编码、probe/replay 与临时工作区。此次相同 peak 不能被改写成压缩降低了峰值。
- 三次正式计时没有构造包装；allocator 审计来自另外的 warmup。每条正式记录链接原始 allocator audit ID。

## 可支持的结论与限制

本数据支持：在此四图、短上下文、同输出协议与当前原型中，压缩减少了视觉表示和 bank owner 的部分驻留字节，但没有观察到相对 Full 的会话时间优势；probe 没有比 periodic 更快。首轮 TTFT 还包含输入准备、视觉 prefill 和量化/残差编码，不能当作 decode 稳态开销。
inter-token 指标仍包含模型前向、Python 调度、margin 读取、probe 双读与同步等原型开销；没有逐 token 原始分布，不报告 P95，也不把它当作纯 kernel 时间。
四张已用于开发的图像不足以支持总体显著性、吞吐、多用户负载、长视觉上下文、跨模型或部署收益。强制输出 Full 的文本不代表压缩方法自然生成时答对了这些题；本报告不计算或推断任何应用准确率。
