# 冻结 64 图主评测

完整保留 17 配置、64 原始图像、每配置 640 题，共 10,880 个回答。

预设比较基准：`asym:periodic`；预设主要新策略：`asym:probe_l7_t0.02`。
统计按 64 张图像聚类；质量为严格规范化 CLEVR exact。主比较使用图像级双侧 sign-flip Monte Carlo p，并对 16 个比较作 Holm 校正。

主要策略 Δ(pp) = -0.312 [-1.719, +1.094]；MC p=0.826926，Holm p=1；修复 7 题，新增错误 9 题。

预设朴素 Asym 控制集合中的最高观察分数为 `asym:random` (392/640)；这只是完整表中的描述性最高值，推断基准始终保持 Periodic。
全部 16 个主比较的 Holm p 都为 1。本轮没有建立预设主要策略的质量优势，也没有据此证明各方法等价。
